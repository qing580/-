# 基于 YOLOv2 的船舶目标检测分类算法说明

资料来源：段敬雅等《基于 YOLOv2 的船舶目标检测分类算法》

## 1. 这篇文章研究的问题

这篇文章要解决的是：如何在复杂海域图像中检测船舶目标，并进一步识别船舶类别。

传统船舶检测方法通常包括目标分割、候选区域生成、人工特征提取和分类器分类等步骤。这类方法依赖人工设计特征，在光照变化、背景复杂、海浪、有雾、逆光、多目标、小目标等实际海况下泛化能力较差，容易出现漏检、误检或分类不准确。

因此，文章提出一种结合 YOLOv2 和 SVM 的船舶检测分类算法。

该算法主要完成两个任务：

- 船舶目标检测：判断图像中哪里有船，并给出目标框。
- 船舶目标分类：判断检测到的船属于舰艇、货船还是渔船。

## 2. 算法核心思想

这篇文章的核心算法可以概括为：

```text
YOLOv2 检测船舶位置
-> 提取检测区域的深度特征
-> 全局平均池化
-> PCA 降维
-> SVM 分类船舶类别
```

也就是说，文章不是单纯使用 YOLOv2 直接完成所有分类，而是将 YOLOv2 作为目标检测和特征提取网络，再把提取到的深度特征交给 SVM 分类器识别船舶类型。

整体流程为：

1. 输入待检测船舶图像。
2. 使用 K-means 对训练集中船舶真实框进行聚类，得到适合船舶尺寸的 anchor boxes。
3. 用这些 anchor boxes 微调训练 YOLOv2。
4. 用训练好的 YOLOv2 预测船舶位置。
5. 如果检测结果达到识别条件，则提取船舶区域的深度特征。
6. 对深度特征做全局平均池化。
7. 用 PCA 对特征降维。
8. 使用 SVM 分类器输出船舶类别。
9. 最终输出检测框和类别结果。

## 3. YOLOv2 负责什么

YOLOv2 是目标检测网络，文章用它完成船舶定位。

对于输入图像，文章将图像缩放到：

```text
608 x 608 x 3
```

这样做是为了增强小目标船舶的检测效果。

经过多个卷积层和池化层后，YOLOv2 输出：

```text
19 x 19 x [B x (5 + 1)]
```

含义是：

- 图像被划分为 `19 x 19` 个网格。
- 每个网格预测 `B` 个 anchor box。
- 每个预测框包含 6 个信息：
  - 中心坐标 `x`
  - 中心坐标 `y`
  - 宽度 `w`
  - 高度 `h`
  - 置信度 `Confidence`
  - 框内目标属于船舶的得分

置信度公式为：

```text
Confidence = P(boat) x IOU(pred, truth)
```

其中：

- `P(boat)` 表示预测框中含有船舶目标的概率。
- `IOU(pred, truth)` 表示预测框和真实框的交并比。

IOU 的公式为：

```text
IOU(pred, truth) = area(pred ∩ truth) / area(pred ∪ truth)
```

检测时，模型会对所有预测框按得分排序，去除低于阈值的框，再通过非极大值抑制去掉重叠度较高的重复框，最终得到船舶目标框。

## 4. 为什么要用 K-means 聚类 anchor boxes

YOLOv2 原始 anchor boxes 来自 VOC、COCO 等通用目标检测数据集，不一定适合船舶图像。

船舶目标有明显特点：

- 宽度通常大于高度。
- 尺寸变化大。
- 小目标较多。
- 远距离船舶目标框比例与普通物体不同。

因此文章使用 K-means 对训练集中 2872 个真实船舶目标框的宽度和高度进行聚类，得到更适合船舶目标的 anchor boxes。

K-means 的目标函数为：

```text
min ΣΣ [1 - IOU(box[i], truth[j])]
```

含义是：让聚类中心框与真实船舶框的 IOU 尽可能大。目标函数越小，说明聚类得到的 anchor boxes 越接近真实船舶框。

文章还使用 average IOU 衡量聚类效果：

```text
average IOU = 所有真实框与最匹配聚类中心框 IOU 的平均值
```

实验发现：

- YOLOv2 原始 anchor boxes 的 average IOU 为 0.558。
- K-means 聚类得到 4 个 anchor boxes 时，average IOU 为 0.603。
- K-means 聚类得到 5 个 anchor boxes 时，average IOU 为 0.628。

因此文章最终采用 `k = 5` 的 anchor boxes 作为较优方案。

## 5. 船舶分类怎么做

YOLOv2 负责检测船在哪里，但文章要进一步识别船舶类型，因此额外设计了基于深度特征和 SVM 的分类流程。

分类类别包括 3 类：

| 类别 | 含义 |
|---|---|
| 舰艇 | warship / guard |
| 货船 | cargo ship |
| 渔船 | fishing boat |

分类流程为：

1. 从原始图像中截取 YOLOv2 检测出的船舶区域。
2. 将船舶区域作为新的分类数据集。
3. 使用训练好的 YOLOv2 网络提取卷积层深度特征。
4. 对特征图进行全局平均池化，把特征图转为特征向量。
5. 使用 PCA 对特征向量降维。
6. 将降维后的特征输入 SVM 分类器。
7. SVM 输出舰艇、货船、渔船中的一个类别。

## 6. 深度特征提取方法

文章从 YOLOv2 网络的不同卷积层提取特征，主要比较了：

- `conv5_1`
- `conv6_1`
- `conv6_5`
- `conv8`
- 多层特征融合

因为检测出的船舶区域尺寸较小，分类网络输入尺寸设为：

```text
224 x 224
```

其中：

- `conv5_1` 层特征大小为 `14 x 14 x 521`
- 其余 3 层特征大小为 `7 x 7 x 1024`

深度特征提取算法可以概括为：

1. 输入 `N` 张样本，设置 `batch size = 16`。
2. 加载特征提取网络权重。
3. 按 batch 预处理输入图像。
4. 提取卷积层特征图。
5. 对特征图做全局平均池化。
6. 返回特征向量和对应标签。
7. 拼接所有样本的特征向量，得到 `N x X` 维特征。

## 7. SVM 分类器

文章使用 SVM 作为最终分类器，原因是：

- SVM 适合小样本分类。
- 深度特征已经包含较强表达能力，SVM 可以在这些特征上做有效分类。
- 相比直接训练大型分类网络，SVM 对数据量要求更低。

文章选择径向基函数作为 SVM 核函数，也就是 RBF 核。

为了选择合适参数，文章测试了 6 组 `gamma` 和 `C`，并使用 10 折交叉验证。

结果如下：

| SVM 参数 | 分类准确率 |
|---|---:|
| gamma = 2^-11, C = 0.5 | 92.81% |
| gamma = 2^-11, C = 1 | 94.35% |
| gamma = 2^-11, C = 2 | 95.03% |
| gamma = 2^-10, C = 0.5 | 90.92% |
| gamma = 2^-10, C = 1 | 92.93% |
| gamma = 2^-10, C = 2 | 93.79% |

因此文章最终选择：

```text
gamma = 2^-11
C = 2
```

## 8. 数据集

文章使用自建船舶图像数据集，来源包括：

- 海上实拍图像
- 网络图像

图像中包含复杂场景，例如：

- 有雾
- 海浪大
- 逆光
- 背景复杂
- 多船目标
- 小尺寸船舶目标

检测数据集划分为：

| 数据集 | 图像数量 |
|---|---:|
| 训练集 | 1670 张 |
| 测试集 | 381 张 |

分类数据集由 YOLOv2 检测出的船舶区域构成：

| 数据集 | 货船 | 渔船 | 舰艇 |
|---|---:|---:|---:|
| 训练集 | 809 张 | 980 张 | 559 张 |

## 9. 实验参数

实验平台为：

- CPU：Intel Core i7-6820HQ
- 内存：16 GB
- GPU：NVIDIA Quadro M1000M
- 系统：Windows 64 位
- Python：3.5.2
- TensorFlow：1.8.0
- OpenCV：3.4.2
- CUDA：9.0
- CUDNN：7.0

YOLOv2 训练参数为：

- `batch size = 16`
- 冲量常数：0.9
- 权值衰减系数：0.0005
- 训练 30 个迭代
- 前 10 个迭代学习率：`10^-4`
- 后 20 个迭代学习率：`10^-5`

## 10. 检测结果怎么得出

检测结果通过 YOLOv2 输出的目标框计算得到。

评价指标包括：

- precision：精确率
- recall：召回率
- AP：平均精确率
- FPS：每秒处理帧数

不同 anchor boxes 下的检测结果为：

| anchor boxes | precision | recall | AP | FPS |
|---|---:|---:|---:|---:|
| YOLOv2 原始 anchor boxes | 0.892 | 0.773 | 0.729 | 10 |
| K-means, k = 4 | 0.768 | 0.836 | 0.776 | 10 |
| K-means, k = 5 | 0.788 | 0.886 | 0.805 | 10 |

由此可见，采用 K-means 聚类得到的 5 个 anchor boxes 后，检测 AP 达到：

```text
80.5%
```

相比 YOLOv2 原始 anchor boxes 的 72.9%，提高了：

```text
7.6%
```

## 11. 与传统检测方法对比

文章将本文方法与 Selective Search 方法进行对比。

Selective Search 方法先生成候选框，再提取 FHOG 特征，最后用 SVM 判断候选框是否为船舶。

对比结果为：

| 方法 | precision | recall | AP | FPS |
|---|---:|---:|---:|---:|
| 本文方法 | 0.788 | 0.886 | 0.805 | 10 |
| Selective Search | 0.644 | 0.374 | 0.322 | 1.2 |

可以看出，本文方法在召回率、平均精确率和检测速度上都明显优于传统 Selective Search 方法。

原因是：

- 传统人工特征对光照、颜色和背景变化敏感。
- 复杂海况下候选框数量多，FHOG 特征难以稳定区分船舶和背景。
- YOLOv2 端到端检测框架能直接学习深度特征，抗干扰能力更强。

## 12. 分类结果怎么得出

分类准确率计算公式为：

```text
accuracy = 分类正确的样本数目 / 总样本数目
```

文章比较了不同卷积层特征的分类效果：

| 特征层 | 分类准确率 |
|---|---:|
| conv5_1 | 87.50% |
| conv6_1 | 90.06% |
| conv6_5 | 88.78% |
| conv8 | 87.18% |
| conv5_1 + conv6_1 | 90.22% |
| conv6_1 + conv6_5 | 90.87% |
| conv6_1 + conv8 | 89.74% |

结果表明：

- 单层特征中，`conv6_1` 效果最好，准确率为 90.06%。
- 多层融合中，`conv6_1 + conv6_5` 效果最好，准确率为 90.87%。

因此文章最终采用：

```text
conv6_1 + conv6_5 深度特征融合 + PCA 降维 + SVM 分类
```

## 13. 与其他分类方法对比

文章还将本文分类方法与 FHOG + SVM、AlexNet 进行对比：

| 方法 | 分类准确率 |
|---|---:|
| FHOG + SVM | 77.16% |
| AlexNet | 86.97% |
| 本文方法 | 90.87% |

结果说明：

- 深度特征明显优于传统 FHOG 人工特征。
- 本文方法比 AlexNet 高 3.9%。
- YOLOv2 中间层特征与 SVM 结合后，对舰艇、货船、渔船的区分能力更强。

## 14. 最终检测分类结果

为了验证完整检测分类框架，文章比较了 YOLOv2 和本文 YOLOv2-SVM 算法对 3 类船舶目标的检测识别效果。

结果如下：

| 方法 | 渔船 AP | 货船 AP | 舰艇 AP | mAP | FPS |
|---|---:|---:|---:|---:|---:|
| YOLOv2 | 0.687 | 0.757 | 0.742 | 0.729 | 9 |
| 本文算法 | 0.740 | 0.713 | 0.838 | 0.764 | 10 |

本文算法相比 YOLOv2，mAP 从 0.729 提高到 0.764，提升约：

```text
3.5%
```

说明 YOLOv2-SVM 框架能更好地完成复杂背景下的船舶检测与类别识别。

## 15. 一条图像怎么得到最终结果

对于一张新的海上图像，最终结果的计算过程是：

1. 将图像缩放到 `608 x 608 x 3`。
2. 输入训练好的 YOLOv2 网络。
3. YOLOv2 在 `19 x 19` 网格上生成多个预测框。
4. 根据置信度筛掉低分框。
5. 使用非极大值抑制去掉重复框。
6. 得到船舶目标位置。
7. 裁剪或提取检测出的船舶区域。
8. 将船舶区域缩放到 `224 x 224`。
9. 从 YOLOv2 的 `conv6_1` 和 `conv6_5` 层提取深度特征。
10. 对特征进行全局平均池化。
11. 使用 PCA 降维。
12. 输入 SVM 分类器。
13. SVM 输出类别：舰艇、货船或渔船。
14. 最终得到船舶检测框和类别标签。

## 16. 一句话总结

这篇文章的方法可以概括为：

> 先用 K-means 聚类得到更适合船舶尺寸的 anchor boxes，并用它们微调 YOLOv2 完成船舶检测；再从 YOLOv2 检测出的船舶区域中提取深度卷积特征，经全局平均池化和 PCA 降维后输入 SVM，完成舰艇、货船、渔船三类识别。

它的主要优点是：

- 检测速度较快。
- 比传统人工特征方法更适合复杂海况。
- 对小目标和多目标船舶有更好的检测能力。
- 分类准确率高于 FHOG + SVM 和 AlexNet。

它的不足是：

- 只研究了舰艇、货船、渔船 3 类。
- 数据集规模仍有限。
- 受 GPU 硬件性能影响，检测速度仍有提升空间。
