# 基于 1DCNN-LSTM 的船舶轨迹分类方法说明

## 1. 论文基本信息

- 论文题目：基于 1DCNN-LSTM 的船舶轨迹分类方法
- 英文题目：Ship Trajectory Classification Method Based on 1DCNN-LSTM
- 作者：崔彤彤、王桂玲、高静
- 期刊：Computer Science，Vol.47，No.9，Sep.2020
- DOI：10.11896/jsjkx.191000162

说明：这篇论文研究的是“船舶轨迹分类”，不是图像里的“船舶目标检测分类”。它不看船的外观图片，而是利用 AIS 轨迹数据判断船舶类型。

## 2. 这个算法具体是什么

论文提出的是一种混合深度学习模型：

```text
1DCNN-LSTM = 一维卷积神经网络 + 长短期记忆网络
```

它的核心思想是：

- 1DCNN 负责学习船舶轨迹的“分布特征”
- LSTM 负责学习船舶轨迹的“时间变化特征”
- 最后把两个模型的分类结果加权融合，得到最终船舶类别

可以简单理解为：

```text
AIS轨迹数据
  ↓
数据预处理
  ↓
提取两类特征
  ├─ 分布特征 → 1DCNN → 船型概率
  └─ 时间序列特征 → LSTM → 船型概率
  ↓
加权融合
  ↓
输出最终船舶类型
```

## 3. 它要解决的问题

传统基于图像或视频的船舶分类容易受设备视野、天气、距离、遮挡和监控成本影响。AIS 数据可以连续记录船舶运动状态，因此可以通过“船怎么走”反推“船是什么类型”。

论文认为，只用普通 CNN 或只用 LSTM 都有不足：

- 普通二维 CNN 不适合直接处理一维轨迹序列
- 单独 LSTM 主要学习时间变化，但对不同船型的整体运动分布利用不足
- 只看某一种轨迹特征，分类效果不够稳定

所以论文把 1DCNN 和 LSTM 结合起来。

## 4. 使用的数据是什么

论文使用的是 AIS 数据。

原始 AIS 数据经过筛选后，主要使用字段包括：

| 字段 | 含义 | 作用 |
|---|---|---|
| utc | 时间戳 | 判断轨迹点先后顺序 |
| mmsi | 船舶唯一识别码 | 区分不同船舶 |
| lon | 经度 | 表示船舶位置 |
| lat | 纬度 | 表示船舶位置 |

后续根据轨迹点进一步计算运动特征：

| 特征 | 含义 |
|---|---|
| v | 航速 |
| a | 加速度 |
| h | 航向或方向角相关特征 |
| s | 轨迹偏移、转向或运动状态相关特征 |

论文实验数据来自渤海区域 2016 年 6 月 AIS 数据，分类对象包括 5 类典型船舶：

- 渔船
- 客船
- 油船
- 集装箱船
- 散货船

预处理后用于实验的轨迹样本约为 154958 条，并按约 70% 训练集、30% 测试集进行实验。

## 5. 数据预处理怎么做

由于 AIS 原始数据量大、噪声多、轨迹点稀疏，论文先进行预处理。

### 5.1 按 MMSI 整理轨迹

MMSI 是船舶的唯一编号。算法先把相同 MMSI 的轨迹点归为一组。

```text
原始AIS点：
<mmsi, utc, lon, lat>

按mmsi分组后：
某一艘船 = 按时间排列的一串轨迹点
```

### 5.2 按时间排序

同一艘船的轨迹点需要按照 `utc` 从早到晚排序，形成完整轨迹序列。

### 5.3 过滤异常轨迹点

论文使用基于 MapReduce 的轨迹预处理方法，适合处理大规模 AIS 数据。

主要过滤逻辑是：

- 如果相邻轨迹点时间间隔过大，认为轨迹不连续
- 如果相邻轨迹点空间距离过大，认为可能存在异常点
- 删除不满足条件的轨迹点或轨迹段
- 保留较连续、较可靠的轨迹序列

## 6. 特征怎么提取

这篇论文最关键的地方是提取了两类特征。

## 6.1 分布特征向量

分布特征描述的是一艘船在一段轨迹中，各种运动状态出现的比例。

论文对轨迹中的 4 类运动特征进行统计：

```text
航速 v
加速度 a
航向/方向角 h
运动状态相关特征 s
```

每个特征被划分成 60 个区间，统计轨迹点落入每个区间的比例。

所以：

```text
4 个特征 × 每个特征 60 个区间 = 240 维分布特征向量
```

形式上可以理解为：

```text
一艘船的轨迹
  ↓
统计 v、a、h、s 的分布
  ↓
得到 1 × 240 的向量
  ↓
送入 1DCNN
```

不同类型船舶的运动分布不同。例如渔船、客船、油船、集装箱船、散货船在速度、方向变化、加速度等方面会呈现不同规律。

## 6.2 时间序列特征向量

时间序列特征描述的是轨迹随时间变化的过程。

论文构造的时间序列输入大致包括：

```text
T = [utc, v, h]
```

也就是把船舶在连续时刻的时间、航速、方向相关信息组成序列，再送入 LSTM。

LSTM 擅长处理“前后有关联”的数据，所以适合学习：

- 船舶速度随时间如何变化
- 航向是否经常改变
- 轨迹是否平稳
- 某类船舶是否具有固定运动节奏

## 7. 1DCNN 做了什么

1DCNN 是一维卷积神经网络。

在这篇论文中，1DCNN 的输入是分布特征向量，也就是前面得到的 240 维特征。

它的作用是：

```text
从整体运动分布中提取船型差异
```

例如：

- 渔船可能速度变化和方向变化更复杂
- 客船可能航线更稳定
- 油船、散货船可能速度和航向变化更平缓
- 集装箱船可能有较明显的固定航线特征

1DCNN 经过卷积层、ReLU 激活、全连接层和 Softmax 后，输出 5 个类别概率：

```text
P_F = [渔船概率, 客船概率, 油船概率, 集装箱船概率, 散货船概率]
```

## 8. LSTM 做了什么

LSTM 是长短期记忆网络，适合处理序列数据。

在这篇论文中，LSTM 的输入是时间序列特征向量。

它的作用是：

```text
从轨迹的时间变化过程中提取船型差异
```

LSTM 通过输入门、遗忘门、输出门保留重要历史信息，过滤不重要信息。最后同样通过全连接层和 Softmax 输出 5 个类别概率：

```text
P_S = [渔船概率, 客船概率, 油船概率, 集装箱船概率, 散货船概率]
```

## 9. 最后怎么得出结果

论文不是简单选择 1DCNN 或 LSTM 的结果，而是把两个模型的结果进行加权融合。

融合公式可以理解为：

```text
最终概率 P = 1DCNN输出概率 × 分布特征权重 + LSTM输出概率 × 时间特征权重
```

即：

```text
P = P_F × W_F + P_S × W_S
```

其中：

- `P_F` 是 1DCNN 输出的船型概率
- `P_S` 是 LSTM 输出的船型概率
- `W_F` 是分布特征的权重
- `W_S` 是时间序列特征的权重

论文根据不同船型设置不同权重。可见内容中给出的权重大致为：

```text
W_F = [0.85, 0.80, 0.15, 0.20, 0.25]
W_S = [0.15, 0.20, 0.85, 0.80, 0.75]
```

这说明：

- 对部分船型，分布特征更重要
- 对部分船型，时间序列特征更重要
- 不同船型不能用完全相同的判断依据

最终选择概率最大的类别作为分类结果：

```text
最终类别 = argmax(P)
```

例如：

```text
P = [0.05, 0.08, 0.72, 0.10, 0.05]

最大值是 0.72
所以该轨迹被分类为油船
```

## 10. 实验结果是什么

论文使用准确率、精确率、召回率和 F1 值评价模型。

### 10.1 不同模型准确率对比

论文表 4 给出的结果为：

| 模型 | 准确率 |
|---|---:|
| LSTM | 83.3% |
| 1DCNN | 87.2% |
| 1DCNN-LSTM | 91.7% |

可以看出，融合模型效果最好。

### 10.2 1DCNN 参数实验

论文还比较了不同卷积核大小下 1DCNN 的准确率：

| 卷积核大小 | 准确率 |
|---|---:|
| 3 | 83.27% |
| 4 | 85.22% |
| 5 | 87.17% |
| 6 | 86.10% |
| 7 | 84.98% |

结果显示，卷积核大小为 5 时效果较好。

### 10.3 5 类船型识别结果

论文中的混合模型对 5 类船型都进行了分类，表 3 显示各类船舶的精确率、召回率、F1 值整体较高。其中可见数据包括：

| 船型 | Precision | Recall | F1 |
|---|---:|---:|---:|
| 渔船 | 94.3% | 95.7% | 94.9% |
| 客船 | 96.4% | 96.8% | 96.6% |
| 油船 | 84.7% | 90.1% | 87.3% |
| 集装箱船 | 92.6% | 88.5% | 90.5% |
| 散货船 | 90.1% | 86.9% | 88.5% |

整体来看，客船和渔船识别效果较好，油船、散货船和集装箱船之间更容易混淆。

## 11. 这篇论文的创新点

### 11.1 不用船舶图片，而用 AIS 轨迹分类

它不是通过外观判断船型，而是通过船舶运动行为判断船型。

### 11.2 同时考虑分布特征和时间特征

论文认为船舶轨迹里有两类信息：

- 分布信息：这艘船整体运动状态是什么样
- 时间信息：这艘船的运动状态如何随时间变化

单独使用一种信息不够，因此把二者结合。

### 11.3 用 MapReduce 处理大规模 AIS 数据

AIS 数据量很大，论文使用 MapReduce 完成轨迹分组、排序、过滤和特征提取，适合海量轨迹数据处理。

### 11.4 按船型设置融合权重

不同船型依赖的特征不同，论文给 1DCNN 和 LSTM 的输出设置不同权重，从而提高分类准确率。

## 12. 如果自己实现，需要怎么做

可以按下面流程实现：

### 第一步：采集 AIS 数据

需要字段：

```text
mmsi, utc, lon, lat
```

最好再有船型标签，例如：

```text
fish, passenger, tanker, container, bulk-cargo
```

如果原始 AIS 数据没有船型标签，需要从船舶静态信息、船舶登记数据或人工标注中补充。

### 第二步：轨迹预处理

处理内容：

- 删除缺失值
- 删除经纬度异常值
- 按 MMSI 分组
- 按时间排序
- 删除时间间隔过大或空间跳变过大的轨迹点
- 将每艘船的轨迹切分成样本

### 第三步：计算运动特征

根据相邻轨迹点计算：

- 航速
- 加速度
- 航向角
- 航向变化
- 轨迹偏移或转向相关指标

### 第四步：构造 1DCNN 输入

对运动特征做区间统计，得到分布向量：

```text
每艘船轨迹 → 1 × 240 分布特征向量
```

### 第五步：构造 LSTM 输入

按时间顺序保留轨迹序列：

```text
每艘船轨迹 → [utc, v, h] 时间序列
```

### 第六步：训练两个模型

分别训练：

```text
1DCNN模型：输入分布特征，输出船型概率
LSTM模型：输入时间序列特征，输出船型概率
```

### 第七步：结果融合

使用加权融合：

```text
P = P_F × W_F + P_S × W_S
```

然后取最大概率对应的类别作为最终结果。

## 13. 和前面几篇论文的关系

### 和 YOLOv2 船舶分类的区别

YOLOv2 论文用的是图片：

```text
船舶图片 → 检测船的位置 → 判断船的类型
```

这篇 1DCNN-LSTM 论文用的是 AIS 轨迹：

```text
AIS轨迹 → 分析船怎么走 → 判断船的类型
```

### 和加权朴素贝叶斯轨迹分类的区别

加权朴素贝叶斯属于传统机器学习方法，模型结构相对简单。

1DCNN-LSTM 属于深度学习方法，可以自动学习复杂特征，尤其适合大规模 AIS 轨迹数据。

## 14. 一句话总结

这篇论文的算法就是：先把 AIS 轨迹按船舶整理和清洗，再提取“分布特征”和“时间序列特征”，分别送入 1DCNN 和 LSTM，最后把两个模型输出的船型概率加权融合，得到渔船、客船、油船、集装箱船、散货船这 5 类船舶的分类结果。
