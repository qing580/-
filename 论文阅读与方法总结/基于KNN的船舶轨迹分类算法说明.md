# 基于 KNN 的船舶轨迹分类算法说明

## 1. 论文基本信息

- 论文题目：基于 KNN 的船舶轨迹分类算法
- 英文题目：Ship trajectory classification algorithm based on KNN
- 作者：刘磊、初秀民、蒋仲廉、钟诚、张代勇
- 期刊：大连海事大学学报，2018 年 8 月，第 44 卷第 3 期
- DOI：10.16411/j.cnki.issn1006-7736.2018.03.003

说明：这篇论文研究的是“船舶轨迹分类”，不是通过图片判断船型，而是根据 AIS 轨迹判断船舶轨迹属于哪一种航行模式或轨迹类别。

## 2. 这个算法具体是什么

论文提出的是一种基于 KNN 的船舶轨迹分类算法。

KNN 的全称是 K-Nearest Neighbor，也就是 K 近邻算法。它的基本思想是：

```text
一个待分类轨迹属于哪一类，要看它离哪些已知类别轨迹最近。
如果最近的 K 条样本轨迹中，大多数属于某一类，
那么这条待分类轨迹也归为这一类。
```

这篇论文的重点不只是直接套用 KNN，而是先设计了适合船舶轨迹的“距离计算方法”。

它把轨迹之间的距离分成三部分：

- 轨迹间平均距离
- 航速距离
- 航向距离

然后把三种距离融合成综合距离，再把综合距离放进 KNN 中完成分类。

整体流程可以理解为：

```text
AIS轨迹数据
  ↓
轨迹预处理
  ↓
轨迹初步聚类
  ↓
选取KNN样本中心轨迹
  ↓
计算待分类轨迹和样本轨迹的距离
  ↓
选出最近的K条轨迹
  ↓
投票得到分类结果
```

## 3. 使用的数据是什么

论文使用的是 AIS 船舶轨迹数据。

实验数据为：

- 区域：长江航道武汉段
- 时间：2017 年 5 月
- 研究范围：左下角坐标约为 `(114.20E, 30.47N)`，右上角坐标约为 `(114.38E, 30.64N)`
- 待分类轨迹数量：2131 条

AIS 数据中至少需要这些内容：

| 数据 | 含义 | 作用 |
|---|---|---|
| MMSI | 船舶唯一识别码 | 区分不同船舶 |
| 时间 | 轨迹点时间 | 按时间排序形成轨迹 |
| 经度 | 船舶位置 | 计算空间距离 |
| 纬度 | 船舶位置 | 计算空间距离 |
| 航速 | 船舶速度 | 计算航速距离 |
| 航向 | 船舶航行方向 | 计算航向距离 |

## 4. 数据预处理怎么做

论文先对 AIS 数据进行预处理，主要包括：

1. 船舶轨迹分离
2. 经纬度数据过滤
3. 删除异常轨迹点
4. 按 MMSI 整理每艘船的轨迹
5. 按时间顺序连接轨迹点

预处理后的轨迹可以表示为：

```text
轨迹 l = [(x1, y1), (x2, y2), ..., (xn, yn)]
```

其中：

- `x` 表示经度
- `y` 表示纬度
- 一条轨迹就是一艘船连续航行位置点组成的序列

## 5. 轨迹相似性怎么计算

KNN 分类的核心是“距离”。  
如果距离算得不好，KNN 分类也会不准。

这篇论文主要比较了三种距离：

- Hausdorff 距离
- 轨迹间平均距离
- 综合距离

## 5.1 Hausdorff 距离

Hausdorff 距离是一种常见的轨迹相似性度量方法，用来衡量两条轨迹之间的最大偏离程度。

但论文指出，Hausdorff 距离容易受到轨迹长度、轨迹点数量和局部异常点影响。对于轨迹点较多的船舶 AIS 数据，它不一定能客观反映两条轨迹的真实相似程度。

因此论文又提出了“轨迹间平均距离”。

## 5.2 轨迹间平均距离

轨迹间平均距离的思想是：

```text
对轨迹1中的每个点，计算它到轨迹2的最短距离；
然后把这些最短距离求平均值。
```

具体做法：

1. 对轨迹 `l1` 中的一个点，计算它到轨迹 `l2` 每一段折线的距离
2. 取其中最小值，作为该点到轨迹 `l2` 的距离
3. 对 `l1` 所有点重复这个过程
4. 对所有最小距离求平均，得到两条轨迹之间的平均距离

可以简单写成：

```text
轨迹间平均距离 = 所有轨迹点到另一条轨迹最短距离的平均值
```

这个距离比 Hausdorff 距离更平稳，不会因为某一个异常点就严重影响整体结果。

## 5.3 航速距离

船舶在不同航线、不同方向上航速会有明显差异。例如在内河中，上行船和下行船会受到水流影响，速度特征不同。

论文把两条轨迹的航速特征进行比较，使用了：

- 最大航速差异
- 最小航速差异
- 平均航速差异
- 中位数航速差异

航速距离可以理解为：

```text
航速距离 = 两条轨迹在速度特征上的差异
```

## 5.4 航向距离

航向表示船舶运动方向。  
在长江航道这类内河场景中，上行和下行船舶航向可能相差约 180 度，所以航向是判断轨迹类别的重要特征。

论文同样使用：

- 最大航向差异
- 最小航向差异
- 平均航向差异
- 中位数航向差异

航向距离可以理解为：

```text
航向距离 = 两条轨迹在方向特征上的差异
```

## 5.5 综合距离

由于轨迹空间距离、航速距离、航向距离的单位不同，论文先进行归一化：

```text
d' = (d - dmin) / (dmax - dmin)
```

归一化后，不同类型的距离都变成 0 到 1 之间的可比较数值。

然后按权重融合：

```text
Dis(l1, l2) = wl × dl' + wv × dv' + wc × dc'
```

其中：

- `dl'` 表示归一化后的轨迹空间距离
- `dv'` 表示归一化后的航速距离
- `dc'` 表示归一化后的航向距离
- `wl`、`wv`、`wc` 是三个权重
- 三个权重都大于 0 且小于 1，并且加起来等于 1

也就是说，论文不是只看“轨迹形状像不像”，而是同时考虑：

```text
轨迹走向像不像 + 航速像不像 + 航向像不像
```

## 6. KNN 分类具体怎么做

论文中的 KNN 分类流程如下：

1. 计算待分类轨迹与所有已知样本轨迹之间的距离
2. 按照距离从小到大排序
3. 选取距离最近的 K 条轨迹
4. 统计这 K 条轨迹分别属于哪些类别
5. 哪个类别出现次数最多，待分类轨迹就归为哪个类别

论文中 K 的取值为：

```text
K = 5
```

举个例子：

```text
待分类轨迹 A

最近的 5 条样本轨迹类别：
类别1、类别1、类别1、类别2、类别3

类别1 出现 3 次，最多
所以轨迹 A 被分为类别1
```

## 7. 初步聚类和样本轨迹怎么选

论文不是一开始就直接做 KNN，而是先进行轨迹初步聚类。

## 7.1 研究区域划分

论文把长江武汉段研究水域划分为若干子区域，例如图中包含：

```text
区域 a、区域 b、区域 c、区域 d
```

然后根据船舶轨迹的起点和终点所在区域，对轨迹进行初步分类。

例如：

```text
从区域 a 到区域 b → 记为 a 至 b 类轨迹
从区域 b 到区域 a → 记为 b 至 a 类轨迹
从区域 a 到区域 c → 记为 a 至 c 类轨迹
```

这样可以先得到几类典型航行轨迹。

## 7.2 选取 KNN 样本中心轨迹

为了让 KNN 的样本轨迹更有代表性，论文根据以下因素评价轨迹：

- 轨迹长度
- 航速标准差
- 航向标准差

论文中对应权重为：

```text
轨迹长度权重：0.4
航速标准差权重：0.3
航向标准差权重：0.3
```

然后在每一类轨迹中排序，选取排名靠前的轨迹作为 KNN 分类样本轨迹。

## 8. 怎么得出最终结果

最终结果是通过 KNN 投票得到的。

以综合距离为例：

```text
输入：一条待分类船舶轨迹
  ↓
计算它与每条样本轨迹的综合距离
  ↓
按距离从小到大排序
  ↓
取最近的 5 条样本轨迹
  ↓
统计这 5 条轨迹的类别
  ↓
出现次数最多的类别 = 最终分类结果
```

所以这篇论文的“结果”不是神经网络输出的概率，而是：

```text
最近邻样本投票后的轨迹类别
```

## 9. 实验结果是什么

论文做了两组主要实验。

## 9.1 单一距离下的 KNN 分类

第一组实验只比较空间轨迹距离，不加入航速和航向。

| 距离方法 | 分类准确率 |
|---|---:|
| Hausdorff 距离 | 65.83% |
| 轨迹间平均距离 | 99.17% |

结论：

```text
当船舶轨迹点较多时，轨迹间平均距离比 Hausdorff 距离更适合用于 KNN 轨迹分类。
```

## 9.2 综合距离下的 KNN 分类

第二组实验加入航速和航向特征，构建综合距离。

| 综合距离形式 | 分类准确率 |
|---|---:|
| Hausdorff 距离 + 航速 + 航向 | 97.50% |
| 轨迹间平均距离 + 航速 + 航向 | 97.50% |

结论：

```text
航速和航向是船舶轨迹分类中的重要先验特征。
把航速、航向加入距离计算后，可以明显提升分类效果。
```

尤其是对于 Hausdorff 距离来说，单独使用时准确率只有 65.83%，加入航速和航向后提高到 97.50%。

## 10. 这篇论文的创新点

### 10.1 提出轨迹间平均距离

针对 Hausdorff 距离受轨迹长度和局部异常影响的问题，论文提出用轨迹点到另一条轨迹的平均最短距离来衡量相似性。

### 10.2 把航速和航向加入轨迹分类

论文认为船舶轨迹不能只看空间形状，还要看船舶运动特征。  
因此把航速距离和航向距离加入综合距离。

### 10.3 用 KNN 做轨迹分类

KNN 算法简单、直观，不需要复杂训练过程，只要有代表性的样本轨迹，就可以对新轨迹进行分类。

### 10.4 适合内河航道轨迹分类

论文以长江武汉段为例。内河航道方向性强，上下行轨迹明显，航速和航向特征对分类很有帮助。

## 11. 如果自己实现，需要怎么做

可以按下面步骤实现。

### 第一步：采集 AIS 数据

需要采集：

```text
MMSI
时间
经度
纬度
航速
航向
```

### 第二步：轨迹预处理

处理内容包括：

- 按 MMSI 区分船舶
- 按时间排序
- 删除经纬度异常点
- 删除速度异常点
- 删除时间间隔过大的轨迹段
- 形成每艘船的完整轨迹

### 第三步：研究区域划分

把研究水域划分成若干区域，例如：

```text
区域 a、区域 b、区域 c、区域 d
```

根据轨迹起点和终点确定初步类别。

### 第四步：选取样本轨迹

在每个类别中选择有代表性的轨迹作为 KNN 样本轨迹。

可以参考论文的评价指标：

```text
轨迹长度
航速标准差
航向标准差
```

### 第五步：计算距离

对每条待分类轨迹，计算它和样本轨迹之间的距离：

```text
轨迹间平均距离
航速距离
航向距离
综合距离
```

### 第六步：KNN 投票分类

设定：

```text
K = 5
```

然后选择最近的 5 条样本轨迹，按照类别投票，出现次数最多的类别就是最终分类结果。

## 12. 和前面几篇论文的关系

### 和 YOLOv2 船舶分类的区别

YOLOv2 用的是图像：

```text
船舶图片 → 检测船在哪里 → 判断船是什么类型
```

KNN 轨迹分类用的是 AIS：

```text
AIS轨迹 → 判断轨迹属于哪一类航行模式
```

### 和加权朴素贝叶斯轨迹分类的区别

加权朴素贝叶斯会先学习各类别的概率分布，再根据概率判断类别。

KNN 不需要训练复杂模型，而是直接比较待分类轨迹与样本轨迹的距离。

### 和 1DCNN-LSTM 轨迹分类的区别

1DCNN-LSTM 是深度学习方法，需要训练神经网络。

KNN 是传统机器学习方法，结构更简单，更容易解释，但分类效果依赖距离设计和样本轨迹质量。

## 13. 一句话总结

这篇论文的算法就是：先用 AIS 数据整理出船舶轨迹，再根据轨迹起终点做初步聚类并选出样本轨迹，然后用轨迹间平均距离、航速距离和航向距离构成综合距离，最后用 KNN 找最近的 5 条样本轨迹，通过投票得到待分类轨迹的类别。
