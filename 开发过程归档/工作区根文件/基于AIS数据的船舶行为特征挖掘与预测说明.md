# 基于 AIS 数据的船舶行为特征挖掘与预测说明

资料来源：甄荣、邵哲平、潘家财《基于 AIS 数据的船舶行为特征挖掘与预测：研究进展与展望》

## 1. 这篇文章研究的问题

这篇文章不是提出一个单独的新算法，而是一篇综述论文。它研究的是：如何利用 AIS 数据挖掘船舶行为特征，并进一步预测船舶未来行为。

AIS 数据中包含船舶的动态信息、静态信息和航次相关信息。通过对这些数据进行清洗、聚类、建模和预测，可以发现船舶航行规律、典型航路、异常行为、会遇风险和未来轨迹。

文章主要总结了 3 类研究方向：

```text
AIS 水上交通要素挖掘
-> 船舶行为聚类
-> 船舶行为预测
```

## 3. 文章总结出的三大研究主题

通过关键词聚类，文章把研究内容分为 3 个主线：

| 研究主题 | 主要内容 |
|---|---|
| AIS 水上交通要素挖掘 | 轨迹预处理、交通流参数、船舶会遇 |

## 4. AIS 数据需要采集哪些内容

进行船舶行为特征挖掘与预测，需要采集以下 AIS 字段。

### 4.1 动态信息

动态信息是预测船舶行为最重要的数据：

| 字段 | 含义 |
|---|---|
| MMSI | 船舶识别码 |
| latitude | 纬度 |
| longitude | 经度 |
| SOG | 对地航速 |
| COG | 对地航向 |
| heading | 船首向 |
| ROT | 转向率 |
| timestamp | 时间戳 |

这些数据可以用来恢复船舶轨迹、计算速度变化、航向变化、加速度、转向行为和未来位置。

### 4.2 静态信息

静态信息用于理解船舶类型和尺度差异：

| 字段 | 含义 |
|---|---|
| ship_type | 船舶类型 |
| length | 船长 |
| width | 船宽 |
| draught | 吃水 |
| name | 船名 |
| call_sign | 呼号 |

不同船型的航速、航路、转向能力和风险特征不同，因此静态信息对行为解释很重要。

### 4.3 航次信息

航次信息用于判断船舶意图：

| 字段 | 含义 |
|---|---|
| destination | 目的港 |
| ETA | 预计到达时间 |
| navigation_status | 航行状态 |

例如，锚泊、靠泊、正常航行、受限操纵等状态，对行为识别和异常判断都有影响。

## 5. AIS 水上交通要素挖掘

这是第一类研究，目标是从 AIS 数据中提取水上交通特征。

主要包括：

```text
轨迹数据预处理
交通流特征参数分析
船舶会遇分析
```

## 6. 轨迹数据预处理

AIS 数据在传输和接收过程中可能存在错误、缺失和中断，因此必须先进行预处理。

### 6.1 轨迹清洗

轨迹清洗主要删除异常数据，例如：

- MMSI 为 0；
- 经纬度超出合理范围；
- 航速异常；
- 航向异常；
- 时间戳错误；
- 明显跳点；
- 重复数据。

清洗的目的是保证后续轨迹挖掘和预测计算的准确性。

### 6.2 轨迹插值

由于 AIS 设备故障、信号遮挡或接收不完整，轨迹中可能存在缺失点，需要插值补全。

常见插值方法包括：

- 线性插值；
- 三次样条插值；
- 拉格朗日插值；
- 均值插值；
- 向量函数插值；
- 复合插值；
- 基于机器学习的插值。

简单插值方法容易实现，但对复杂运动不一定准确。机器学习方法精度可能更高，但解释性较弱。

### 6.3 轨迹融合

船舶 AIS 数据和雷达数据具有互补性：

- AIS 能提供船舶身份、航速、航向、类型等信息；
- 雷达能主动探测目标方位、距离、形状和水域背景。

常见融合方法包括：

- 统计加权方法；
- BP 神经网络方法；
- 卡尔曼滤波方法；
- 时间序列聚类方法；
- 集成融合方法。

轨迹融合的目标是获得更完整、更可靠的船舶轨迹。

### 6.4 轨迹压缩

AIS 数据量很大，长期存储和实时计算成本较高，因此需要轨迹压缩。

常见离线压缩方法包括：

- Douglas-Peucker，简称 DP 算法；
- Dead Reckoning；
- OLDCAT；
- 扫描-选择-移动算法。

常见在线压缩方法包括：

- 滑动窗口方法；
- 在线有向无环图方法。

轨迹压缩的目标是在尽量保留关键航迹点和行为特征的前提下，减少数据量，提高计算效率。

## 7. 交通流特征参数分析

交通流特征用于描述某个水域中船舶交通的整体规律。

常见参数包括：

- 船舶位置分布；
- 船舶速度分布；
- 船舶方向分布；
- 船舶数量；
- 船舶间时间间隔；
- 航道内船舶到达规律；
- 交通流风险参数。

研究方法主要包括：

- 数理统计；
- 分布函数拟合；
- 数据场方法；
- Delaunay 剖分插值；
- 数据聚类。

这些结果可以用于交通组织、航道规划、风险区域识别和通航效率分析。

## 8. 船舶会遇分析

船舶会遇是碰撞风险分析的基础。

研究内容包括：

- 船舶会遇时空特征；
- 会遇船舶数量；
- 会遇最近距离；
- 会遇态势；
- 会遇船舶紧迫度。

常见方法包括：

- 会遇时空特征统计；
- 船舶运动几何关系分析；
- 空间约束模型；
- 热力图可视化；
- 自适应理解模型；
- 支持向量机；
- 贝叶斯网络。

会遇分析可以为水上交通高风险区域监控和船舶操纵决策提供依据。

## 9. 船舶行为聚类

船舶行为聚类是第二类研究，目标是从大量 AIS 轨迹中自动发现典型航行模式。

聚类对象可以分为：

```text
轨迹点聚类
轨迹段聚类
```

其中轨迹点聚类关注离散 AIS 点的空间分布，轨迹段聚类更关注连续航行过程中的行为模式。

## 10. 轨迹距离和相似度计算

轨迹聚类之前，必须先计算轨迹之间的相似度。

常见距离方法包括：

- 欧氏距离；
- 切比雪夫距离；
- 结构相似度距离；
- Hausdorff 距离；
- 动态时间弯矩距离；
- 基于行为特征的距离；
- 基于复合特征的距离；
- 基于深度卷积和自编码器的距离。

不同距离适用场景不同：

- 欧氏距离适合长度相同、点对应关系明确的轨迹；
- Hausdorff 距离适合长度不一致的轨迹；
- 动态时间弯矩距离适合速度变化和采样时间不同的轨迹；
- 深度学习方法可以自动学习轨迹低维特征。

距离计算方法会直接影响聚类结果。

## 11. 轨迹点聚类方法

轨迹点聚类可分为 3 类：

| 方法类型 | 代表方法 |
|---|---|
| 基于划分的聚类 | k-means、k-medoids |
| 基于密度的聚类 | DBSCAN、密度峰值快速搜索与聚类 |
| 基于层次的聚类 | AGNES 层次聚类 |

### 11.1 k-means

k-means 需要提前指定聚类数量，适合发现较规则的航路中心，但对异常点和初始参数较敏感。

### 11.2 DBSCAN

DBSCAN 不需要提前指定类别数，适合发现高密度航迹区域和异常点，因此在船舶轨迹点聚类中应用较多。

### 11.3 层次聚类

层次聚类可以生成聚类树，便于观察不同尺度下的轨迹聚类结果，但计算量相对较大。

## 12. 轨迹段聚类方法

轨迹段聚类用于提取更完整的船舶行为模式。

研究内容包括：

- 船舶交通行为模式提取；
- 船舶操纵行为特征推断；
- 航路框架提取；
- 船舶转向点识别；
- 高碰撞风险区域识别。

常见方法包括：

- 密度聚类；
- 层次聚类；
- 谱聚类；
- 拉普拉斯特征聚类；
- DP 压缩 + DBSCAN；
- 多步子航迹聚类；
- 随机邻居嵌入；
- 概率图模型。

轨迹段聚类比轨迹点聚类更能反映真实航行行为。

## 13. 船舶行为预测

船舶行为预测是第三类研究，目标是根据历史 AIS 序列预测未来位置、速度、航向或行为类别。

文章将预测方法分为 4 类：

```text
基于动力学方程的方法
基于传统智能算法的方法
基于深度循环神经网络的方法
基于深度卷积神经网络的方法
```

## 14. 基于动力学方程的预测

这类方法根据船舶运动学或动力学关系进行预测。

常见方法包括：

- 高斯跟踪滤波；
- 卡尔曼滤波；
- 灰色预测；
- 矢量分析；
- 惯性定位原理。

优点：

- 有明确物理意义；
- 适合已知船舶运动参数的场景；
- 解释性较强。

缺点：

- 需要较准确的船舶操纵参数；
- 风、浪、流等环境扰动会降低预测精度；
- 对复杂机动行为适应性有限。

## 15. 基于传统智能算法的预测

这类方法使用传统机器学习或浅层神经网络进行预测。

常见方法包括：

- BP 神经网络；
- k 近邻；
- 支持向量机。

一种典型做法是：

```text
输入：历史时刻的经纬度、航速、航向
输出：未来时刻的经纬度、航速、航向
```

例如，可以用 `t-1` 时刻的经纬度、航速、航向作为输入，预测 `t`、`t+1`、`t+2` 时刻的状态。

优点：

- 比纯动力学方法更能拟合非线性行为；
- 对部分复杂场景有更好的适应性。

缺点：

- 参数调节困难；
- 容易陷入局部最优；
- 对时间序列长期依赖建模不足；
- 泛化能力受训练样本影响较大。

## 16. 基于深度循环神经网络的预测

深度循环神经网络是当前船舶行为预测的重要方向。

常见模型包括：

- LSTM；
- GRU；
- 注意力机制；
- Seq2Seq；
- 生成对抗网络；
- 混合神经网络。

这类方法把 AIS 轨迹看作时间序列：

```text
[lat, lon, SOG, COG] at t-n ... t
-> model
-> [lat, lon, SOG, COG] at t+1 ... t+k
```

优点：

- 能处理时间序列；
- 能学习长期依赖；
- 预测精度通常高于 BP 神经网络；
- 适合轨迹预测、位置预测和行为状态预测。

缺点：

- 需要大量训练数据；
- 训练时间较长；
- 对异常数据和缺失数据敏感；
- 可解释性较弱。

## 17. 基于深度卷积神经网络的预测

CNN 原本常用于图像识别。应用到 AIS 行为预测时，可以把船舶轨迹转换为图像或矩阵特征。

常见做法包括：

- 将带标签的 AIS 轨迹转化为运动图像；
- 使用 CNN 分类船舶行为模式；
- 结合 CNN 和 LSTM 预测船舶行为；
- 构建多视图特征融合网络；
- 将会遇或碰撞风险场景转化为图像进行分类。

优点：

- 对空间结构特征表达能力强；
- 适合行为分类和场景风险识别；
- 可与 LSTM 等时间序列模型结合。

缺点：

- 需要构造合适的轨迹图像或矩阵；
- 需要标注行为类别；
- 数据量大时标注成本高。

## 18. 结果是怎么得出来的

这篇文章的“结果”主要来自文献计量分析和综述归纳，不是某一个模型训练后的准确率。

结果形成过程如下：

1. 在 WOS 和 CNKI 中检索 2010-2020 年相关文献。
2. 得到 116 篇英文文献和 114 篇中文文献。
3. 统计每年发文数量，分析研究热度变化。
4. 使用 VOSviewer 对关键词进行聚类。
5. 根据关键词共现关系形成研究主题聚类图。
6. 根据关键词时间变化形成趋势演化图。
7. 结合文献内容，将研究方向归纳为水上交通要素挖掘、船舶行为聚类、船舶行为预测 3 类。
8. 对每一类研究整理主要内容、方法、问题和发展方向。

因此，这篇文章得出的结论不是“某算法准确率多少”，而是“当前 AIS 船舶行为研究主要集中在哪些方向、用了哪些方法、还存在哪些问题”。

## 19. 文章得到的主要结论

### 19.1 AIS 水上交通要素挖掘方面

现有研究主要关注：

- 船舶轨迹数据预处理；
- 船舶交通流空间特征；
- 船舶交通流时间特征；
- 船舶会遇特征。

不足是：

- 对 AIS 时间、空间、船舶静态特征和环境特征的关联挖掘不够；
- 多维特征融合仍需加强；
- 可视化分析和语义解释还不充分。

### 19.2 船舶行为聚类方面

现有研究主要使用无监督聚类方法对轨迹点和轨迹段进行聚类。

主要目标是得到：

- 航行行为模式；
- 典型航路；
- 高密度航迹区域；
- 异常航迹；
- 船舶操纵意图。

不足是：

- 轨迹相似度计算仍需优化；
- 聚类参数自适应选择困难；
- 行为语义建模不足；
- 对环境因素和船舶影响因素考虑不足。

### 19.3 船舶行为预测方面

现有研究主要包括：

- 动力学方程预测；
- 传统智能算法预测；
- LSTM、GRU 等深度循环神经网络预测；
- CNN 及 CNN-LSTM 等深度模型预测。

发展趋势是：

- 混合神经网络模型；
- 神经网络与支持向量机结合；
- 注意力机制；
- 多维行为特征实时预测；
- 知识图谱和语义模型辅助解释。

## 20. 适合大创项目的实现方案

如果要把这篇综述用于项目实现，可以设计成一个 AIS 船舶行为挖掘与预测模块。

推荐流程为：

```text
AIS 数据采集
-> 数据清洗
-> 轨迹插值
-> 轨迹压缩
-> 特征提取
-> 轨迹聚类
-> 行为模式识别
-> 轨迹预测
-> 异常行为判断
-> 可视化展示
```

## 21. 可实现的核心功能

第一版可以做以下功能：

### 21.1 轨迹清洗

清洗异常 AIS 数据：

- 经纬度越界；
- MMSI 缺失；
- 时间戳异常；
- 航速异常；
- 航向异常；
- 跳点；
- 重复点。

### 21.2 行为特征提取

从轨迹中提取：

- 平均速度；
- 最大速度；
- 平均航向；
- 航向变化率；
- 转向率；
- 加速度；
- 停留时间；
- 轨迹长度；
- 航迹曲率；
- 区域进入和离开时间。

### 21.3 轨迹聚类

使用 DBSCAN 或 HDBSCAN 对轨迹点进行聚类，发现：

- 主航道；
- 锚地；
- 高频停留区；
- 异常偏航点；
- 高密度交通区域。

### 21.4 轨迹预测

第一版可以先用简单模型：

- 卡尔曼滤波；
- 线性外推；
- GRU 或 LSTM。

输入：

```text
过去 n 个 AIS 点：[lat, lon, SOG, COG]
```

输出：

```text
未来 k 个 AIS 点：[lat, lon]
```

### 21.5 异常行为识别

可识别：

- 偏离主航道；
- 异常减速；
- 异常停留；
- 逆向航行；
- 异常转向；
- AIS 数据中断；
- 进入高风险区域。

## 23. 验证方法

轨迹预测可以用历史 AIS 数据验证：

1. 取一段历史轨迹的前半部分作为输入。
2. 用模型预测后续位置。
3. 将预测轨迹与真实后续轨迹比较。
4. 计算误差。

常用指标包括：

- 平均距离误差；
- 终点距离误差；
- RMSE；
- 预测命中率；
- 异常检测准确率；
- 召回率；
- 误报率。

聚类结果可以通过：

- 可视化地图检查；
- 与航道、锚地、港口位置对比；
- 人工抽样复核；
- 异常航迹案例验证。

## 24. 一句话总结

这篇文章可以概括为：

> 基于 AIS 数据的船舶行为研究，通常先对轨迹进行清洗、插值、融合和压缩，再提取交通流、会遇和轨迹行为特征，利用 k-means、DBSCAN、层次聚类等方法挖掘典型航行模式，最后通过卡尔曼滤波、SVM、BP、LSTM、GRU、CNN 等模型预测船舶未来位置和行为。

对大创项目来说，它最有用的地方是提供了一套总体技术路线：

```text
AIS 轨迹数据
-> 轨迹预处理
-> 行为特征提取
-> 聚类发现航行模式
-> 预测未来轨迹
-> 判断异常行为
-> 可视化解释
```

这个路线可以和船舶碰撞风险、异常轨迹识别、船舶分类、知识图谱和智能体预警系统自然结合。
