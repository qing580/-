# 基于加权朴素贝叶斯的船舶轨迹分类算法说明

资料来源：王维刚等《基于加权朴素贝叶斯的船舶轨迹分类算法》

## 1. 这篇文章研究的问题

这篇文章要解决的是：如何利用船舶 AIS 轨迹数据，对内河船舶轨迹进行快速、准确分类。

AIS 数据中包含船舶的时间、经纬度、航速、航向、转向率等信息。文章将一条船舶轨迹看作一个样本，从中提取轨迹特征，然后判断它属于哪一种航行路径。

文中的实验区域是长江与汉江交汇的武汉河段。作者设置了 3 个断面：

- A：长江航道一端断面
- B：长江航道另一端断面
- C：汉江断面

因此船舶轨迹被划分为 6 类：

| 类别 | 轨迹方向 |
|---|---|
| 类 1 | A -> B |
| 类 2 | A -> C |
| 类 3 | B -> A |
| 类 4 | B -> C |
| 类 5 | C -> A |
| 类 6 | C -> B |

## 2. 算法核心思想

文章使用的是加权朴素贝叶斯分类算法。

简单来说，就是对于一条待分类轨迹，分别计算它属于每一类轨迹的概率，最后把它分到概率最大的那一类。

普通朴素贝叶斯的分类公式为：

```text
Classify(X) = argmax_y P(y) * Π P(X_i | y)
```

其中：

- `X` 表示一条待分类轨迹
- `X_i` 表示轨迹的第 `i` 个特征
- `y` 表示某一个轨迹类别
- `P(y)` 表示类别 `y` 的先验概率
- `P(X_i | y)` 表示在类别 `y` 下出现特征 `X_i` 的条件概率

也就是说，算法会计算：

```text
类别本身出现的概率 * 各个轨迹特征在该类别下出现的概率
```

哪个类别算出来的值最大，这条轨迹就属于哪个类别。

## 3. 为什么要加权

普通朴素贝叶斯默认每个特征同等重要，但在船舶轨迹分类中，不同特征的重要性并不一样。

比如：

- 航向特征对区分上下行轨迹很重要
- 航向方差和最大转向率对区分直行轨迹、弯曲轨迹很重要
- 某些特征可能变化很大，对分类帮助较小

因此文章引入了特征权重。

它的思想是：

> 某个特征在某一类轨迹中越稳定，说明它越能代表这一类轨迹，因此权重越大。

文章用标准差衡量特征稳定性。标准差越小，特征越集中、越稳定；标准差越大，特征越分散、越不稳定。

权重公式为：

```text
w_ij = 1 / σ_ij
```

其中：

- `w_ij` 表示第 `i` 个特征在第 `j` 类轨迹下的权重
- `σ_ij` 表示第 `i` 个特征在第 `j` 类轨迹下的标准差

所以：

- 标准差小，权重大
- 标准差大，权重小

加权后的分类公式为：

```text
Classify(X) = argmax_y P(y_j) * Π [ w_ij * P(X_i | y_j) ]
```

## 4. 连续特征怎么处理

船舶轨迹特征大多是连续值，例如速度、航向、加速度、转向率等，不能直接像离散标签一样统计频率。

因此文章假设这些连续特征在某一类轨迹下服从高斯分布，也就是正态分布。

对于某个类别 `y_j` 和某个特征 `x_i`，条件概率密度为：

```text
P(X_i = x_i | Y = y_j)
```

这个概率由训练集中对应类别的均值和方差估计得到：

- `μ_ij`：第 `j` 类轨迹中第 `i` 个特征的均值
- `σ_ij²`：第 `j` 类轨迹中第 `i` 个特征的方差

所以训练阶段实际上是在统计每一类轨迹中，每个特征的均值、方差和标准差。

## 5. 使用的轨迹特征

文章初步选取了 8 个轨迹特征：

| 编号 | 特征 |
|---|---|
| 1 | 平均速度 |
| 2 | 平均航向 |
| 3 | 平均加速度 |
| 4 | 平均转向率 |
| 5 | 最大转向率 |
| 6 | 航向方差 |
| 7 | 最大航向 |
| 8 | 最小航向 |

这些特征主要来自 AIS 动态信息。

## 6. 特征计算方法

### 6.1 平均速度

对一条轨迹中的所有速度求平均：

```text
v_bar = (v_1 + v_2 + ... + v_n) / n
```

### 6.2 航向统计特征

最大航向：

```text
H_max = max{H_1, H_2, ..., H_n}
```

最小航向：

```text
H_min = min{H_1, H_2, ..., H_n}
```

平均航向：

```text
H_bar = (H_1 + H_2 + ... + H_n) / n
```

航向方差：

```text
D(H) = Σ(H_i - H_bar)^2 / n
```

### 6.3 转向率

相邻两个 AIS 点之间，根据航向差和时间差计算转向率：

```text
v'_m = (H_{m+1} - H_m) / (t_{m+1} - t_m)
```

平均转向率：

```text
v'_bar = (v'_1 + v'_2 + ... + v'_{n-1}) / (n - 1)
```

最大转向率：

```text
v'_max = max{v'_1, v'_2, ..., v'_{n-1}}
```

### 6.4 平均加速度

相邻两个 AIS 点之间，根据速度差和时间差计算加速度：

```text
a_m = (v_{m+1} - v_m) / (t_{m+1} - t_m)
```

平均加速度：

```text
a_bar = (a_1 + a_2 + ... + a_{n-1}) / (n - 1)
```

## 7. 特征筛选方法

文章没有直接使用全部 8 个特征，而是采用序列前向选择算法寻找最优特征子集。

该方法的过程是：

1. 初始特征集合为空。
2. 每次从剩余特征中选择一个加入当前集合。
3. 选择标准是：加入该特征后，分类准确率提升最大。
4. 如果继续加入特征后准确率不再提升，就停止。

实验发现，最优特征加入顺序为：

```text
2 -> 6 -> 7 -> 8 -> 1 -> 5
```

也就是：

```text
平均航向 -> 航向方差 -> 最大航向 -> 最小航向 -> 平均速度 -> 最大转向率
```

最终最优特征子集为：

- 平均航向
- 航向方差
- 最大航向
- 最小航向
- 平均速度
- 最大转向率

平均加速度和平均转向率没有进入最终特征集合，说明它们对分类帮助不明显，甚至可能带来冗余。

## 8. 算法流程

整个算法流程可以概括为：

1. 清洗 AIS 数据，去除异常点和无效数据。
2. 按船舶 MMSI 和时间顺序分离出单条船舶轨迹。
3. 对每条轨迹计算速度、航向、转向率等轨迹特征。
4. 人工标注部分轨迹类别，构建训练集。
5. 使用训练集统计每个类别的先验概率 `P(y)`。
6. 对每个类别、每个特征，估计高斯分布参数 `μ` 和 `σ²`。
7. 根据 `w = 1 / σ` 计算特征权重。
8. 对待分类轨迹，分别计算其属于 6 个类别的加权朴素贝叶斯得分。
9. 选择得分最大的类别作为分类结果。
10. 使用准确率 `ACC` 评价分类效果。

准确率计算公式为：

```text
ACC = T / (T + E)
```

其中：

- `T` 表示预测类别与实际类别相符的轨迹数量
- `E` 表示预测类别与实际类别不相符的轨迹数量

## 9. 实验数据与结果

文章使用 2017 年 5-7 月的武汉河段 AIS 数据。

原始数据包含 220 多万条 AIS 数据。经过清洗和轨迹分离后，共得到 7095 条船舶轨迹。其中 5-6 月数据用于训练和交叉验证，7 月数据用于测试。

为了避免类别数量严重不平衡，作者对数据进行了欠采样处理，构建平衡数据集。

### 9.1 特征累积下的准确率

| 特征集合 | 准确率 |
|---|---:|
| 1 | 47.88% |
| 1, 2 | 97.45% |
| 1, 2, 3 | 96.88% |
| 1, 2, 3, 4 | 96.40% |
| 1, 2, 3, 4, 5 | 97.33% |
| 1, 2, 3, 4, 5, 6 | 98.76% |
| 1, 2, 3, 4, 5, 6, 7 | 98.57% |
| 1, 2, 3, 4, 5, 6, 7, 8 | 98.71% |

可以看出，准确率并不是随着特征数量增加而稳定上升。某些特征加入后反而会降低准确率，所以需要做特征筛选。

### 9.2 最优特征子集结果

| 特征集合 | 准确率 |
|---|---:|
| 2 | 97.50% |
| 2, 7 | 98.28% |
| 2, 6, 7 | 98.88% |
| 2, 6, 7, 8 | 98.95% |
| 2, 6, 7, 8, 1 | 99.01% |
| 2, 6, 7, 8, 1, 5 | 99.05% |

最终最优特征子集的准确率为 99.05%。

### 9.3 加权前后对比

| 算法 | 数据集 | 准确率 |
|---|---|---:|
| 朴素贝叶斯 | 平衡数据集 | 98.57% |
| 朴素贝叶斯 | 原始数据集 | 99.52% |
| 加权朴素贝叶斯 | 平衡数据集 | 99.05% |
| 加权朴素贝叶斯 | 原始数据集 | 99.45% |

在平衡数据集上，加权后准确率由 98.57% 提高到 99.05%。

在原始数据集上，加权后的总体准确率略低于未加权结果，原因是原始数据类别分布不平衡，占比大的类别对总体准确率影响较大。

### 9.4 与其他分类器对比

| 分类器 | 准确率 | 速度 |
|---|---:|---:|
| 支持向量机 | 98.33% | 2100 条/s |
| 决策树 | 98.30% | 3400 条/s |
| K 邻近学习 | 98.81% | 4800 条/s |
| 线性判别分析 | 97.95% | 2900 条/s |
| 朴素贝叶斯 | 98.57% | 8700 条/s |
| 加权朴素贝叶斯 | 99.05% | 8300 条/s |

加权朴素贝叶斯的准确率最高，速度略低于普通朴素贝叶斯，但仍明显快于支持向量机、决策树、KNN 和线性判别分析。

## 10. 怎么得出最终分类结果

对于一条新的 AIS 轨迹，最终结果是这样算出来的：

1. 先计算这条轨迹的 6 个最优特征：
   - 平均航向
   - 航向方差
   - 最大航向
   - 最小航向
   - 平均速度
   - 最大转向率

2. 对 6 个类别分别计算概率得分：

```text
Score(y_j) = P(y_j) * Π [ w_ij * P(X_i | y_j) ]
```

3. 比较 6 个类别的得分。

4. 哪个类别得分最大，就把轨迹分到哪个类别。

例如，如果某条轨迹在类别 1 下的得分最大，那么它就被分类为：

```text
类 1：A -> B
```

## 11. 一句话总结

这篇文章的方法可以概括为：

> 先把 AIS 船舶轨迹转化为航向、速度、转向率等统计特征，再用高斯朴素贝叶斯计算它属于各类航路的概率，同时用标准差倒数给稳定特征更大权重，最后选择概率得分最高的类别作为分类结果。

它的优点是：

- 算法简单
- 训练和分类速度快
- 对 AIS 轨迹分类准确率高
- 适合用于船舶异常轨迹识别和航行风险分析
