# 船舶碰撞风险与避碰决策算法说明

资料来源：《船舶碰撞风险与避碰决策文献总结及实现方案》

## 1. 这个方案研究的问题

这个方案要解决的是：如何根据 AIS 数据判断两艘或多艘船是否存在碰撞风险，并在风险较高时给出避碰决策建议。

它不是一个“自动操船系统”，而是一个岸基 AIS 风险评估与决策支持系统。系统可以做：

- 实时发现危险会遇船舶；
- 计算碰撞风险；
- 给出风险等级；
- 解释风险原因；
- 生成转向、减速、保持航向等候选方案；
- 供值班员或船员人工复核。

它不能直接替代船长、船员或 VTS 作出法律意义上的避碰责任判断。

## 2. 算法核心思想

整体算法可以概括为：

```text
AIS 数据清洗
-> 坐标和速度转换
-> 邻近船筛选
-> CPA/TCPA 计算
-> 碰撞风险指数 CRI 计算
-> 船舶领域侵入判断
-> 会遇类型识别
-> 候选避碰动作生成
-> 规则和区域约束校验
-> 输出风险等级和建议方案
```

简单说，就是先判断船舶是否会在未来某一时刻接近，再综合距离、时间、速度、区域和数据质量等因素给风险打分，最后根据风险等级生成可解释的避碰建议。

## 3. 输入数据

每艘船至少需要 AIS 动态信息：

| 字段 | 含义 |
|---|---|
| MMSI | 船舶唯一识别码 |
| latitude | 纬度 |
| longitude | 经度 |
| SOG | 对地航速 |
| COG | 对地航向 |
| heading | 船首向，可为空 |
| observed_at | AIS 时间戳 |

其中，计算运动趋势时优先使用 `COG`，因为它表示船舶实际对地运动方向。`heading` 表示船首指向，在低速、漂移或转弯时可能和 `COG` 不一致。

## 4. 坐标转换

AIS 中的经纬度不能直接用欧氏距离计算。因此需要先把经纬度转换成局部平面坐标。

对于局部会遇分析，可以把某个参考点作为原点，转换为：

```text
p = [east_m, north_m]
```

其中：

- `east_m` 表示向东距离，单位米；
- `north_m` 表示向北距离，单位米。

在马六甲海峡这种长距离水域中，不能用一个固定平面坐标覆盖全部区域。实际系统中可以按局部会遇船对、网格或动态参考点进行投影。

## 5. 速度向量计算

AIS 中的 SOG 通常单位是节，需要先转换成米每秒：

```text
v_ms = sog_knots x 0.514444
```

COG 是从正北方向顺时针增加的角度，因此速度分解为：

```text
v_east  = v_ms x sin(cog_rad)
v_north = v_ms x cos(cog_rad)
```

对于本船 `O` 和目标船 `T`：

```text
v_O = 本船速度向量
v_T = 目标船速度向量
r   = p_T - p_O
v   = v_T - v_O
```

其中：

- `r` 是目标船相对本船的位置；
- `v` 是目标船相对本船的速度。

## 6. CPA/TCPA 计算

CPA/TCPA 是碰撞风险计算的基础。

### 6.1 TCPA

`TCPA` 表示两船到达最近会遇点所需时间：

```text
TCPA = - (r · v) / ||v||^2
```

含义：

- `TCPA > 0`：如果保持当前速度和航向，两船将在未来达到最近点；
- `TCPA < 0`：最近点已经过去，或两船正在远离；
- `TCPA` 越小，说明危险可能越快发生。

### 6.2 DCPA

`DCPA` 表示两船最近会遇时的距离：

```text
DCPA = || r + TCPA x v ||
```

含义：

- `DCPA` 越小，说明两船未来靠得越近；
- `DCPA` 很小且 `TCPA` 为正时，碰撞风险较高；
- 如果相对速度 `||v||` 很小，TCPA 可能不稳定，应结合当前距离趋势和船舶领域判断。

## 7. 碰撞风险指数 CRI

`CPA/TCPA` 只能描述几何会遇关系。为了输出风险等级，需要把多个因素合成一个风险分数，即 `CRI`。

CRI 可以理解为：

```text
CRI = 多个风险因素的加权综合得分
```

常用因素包括：

- DCPA 风险；
- TCPA 风险；
- 两船是否正在接近；
- 相对速度；
- 会遇类型；
- 航道、交通分离制、锚地等区域因素；
- AIS 数据是否新鲜、是否可信。

## 8. DCPA 风险隶属度

设：

- `D_crit` 为危险距离；
- `D_safe` 为安全距离；
- 且 `D_safe > D_crit`。

DCPA 风险隶属度可表示为：

```text
μ_dcpa = 1                         , DCPA <= D_crit
μ_dcpa = (D_safe - DCPA)
         / (D_safe - D_crit)       , D_crit < DCPA < D_safe
μ_dcpa = 0                         , DCPA >= D_safe
```

解释：

- 当 DCPA 小于危险距离时，距离风险最高；
- 当 DCPA 大于安全距离时，距离风险为 0；
- 中间区间按线性方式变化。

## 9. TCPA 风险隶属度

设：

- `T_crit` 为紧急时间；
- `T_safe` 为安全提前量；
- 且 `T_safe > T_crit`。

TCPA 风险隶属度可表示为：

```text
μ_tcpa = 0                         , TCPA <= 0 或 TCPA >= T_safe
μ_tcpa = (T_safe - TCPA)
         / (T_safe - T_crit)       , T_crit < TCPA < T_safe
μ_tcpa = 1                         , 0 < TCPA <= T_crit
```

解释：

- 如果 TCPA 小于等于 0，说明两船不再接近，未来碰撞风险较低；
- 如果 TCPA 很短，风险很高；
- 如果 TCPA 还很长，则风险较低或只需关注。

## 10. 原型级 CRI 公式

适合大创项目第一版使用的综合风险公式为：

```text
CRI = 0.35 x μ_dcpa
    + 0.25 x μ_tcpa
    + 0.15 x μ_closing
    + 0.15 x μ_area_env
    + 0.10 x μ_data
```

其中：

| 指标 | 含义 |
|---|---|
| `μ_dcpa` | 最近会遇距离风险 |
| `μ_tcpa` | 最近会遇时间风险 |
| `μ_closing` | 是否正在接近、相对速度是否较大 |
| `μ_area_env` | 航道、锚地、交通分离制、环境因素风险 |
| `μ_data` | AIS 数据质量和不确定性 |

最终可以把 `CRI` 转换为 0-100 分：

```text
risk_score = CRI x 100
```

但系统不应该只显示一个分数，还应显示 DCPA、TCPA、会遇类型、主要风险原因和数据可信度。

## 11. 船舶领域模型

船舶不能被看作一个点，因为船有长度、宽度和操纵空间。船舶领域模型就是在船舶周围构造一个动态安全区域。

简单椭圆船舶领域可表示为：

```text
(x/a)^2 + (y/b)^2 = 1
```

其中：

- `x` 是沿船首方向的相对距离；
- `y` 是横向相对距离；
- `a` 是纵向安全半轴；
- `b` 是横向安全半轴。

实际中，船前方安全距离通常大于船后方，因为船舶制动和转向需要更长距离。

可以使用动态参数：

```text
a_forward = k1 x ship_length + k2 x speed x response_time
a_aft     = k3 x ship_length
b_port/starboard = k4 x ship_length + k5 x speed
```

这样船越大、速度越快，安全领域越大。

## 12. 船舶领域侵入风险

如果预测目标船未来位置进入本船安全领域，则风险升高。

设：

- `d` 为目标船相对本船的距离；
- `r_boundary` 为该方向上的船舶领域边界半径；
- `ρ = d / r_boundary`。

领域侵入风险可表示为：

```text
R_domain = 0             , ρ >= 1
R_domain = (1 - ρ)^γ     , 0 <= ρ < 1
```

解释：

- `ρ >= 1`：目标船在领域之外，领域风险为 0；
- `ρ < 1`：目标船进入领域，风险随侵入程度增加；
- `γ` 控制风险上升速度。

## 13. 会遇类型识别

系统还需要识别两船属于哪种会遇场景。

| 会遇类型 | 判断依据 | 处理重点 |
|---|---|---|
| 对遇 | 两船航向近似相反，目标位于本船前方 | 应提前、明显避让 |
| 交叉 | 两船航迹相交，TCPA 为正且 DCPA 较小 | 结合左右舷关系和规则判断 |
| 追越 | 两船航向接近，后船速度更快 | 重点关注后船追越风险 |
| 多船复杂会遇 | 三艘及以上船相互影响 | 不能只做两两独立最优 |

注意：AIS 只能帮助推断“疑似会遇类型”，不能单独用于判断法律责任。

## 14. 速度障碍 VO 与候选避碰动作

速度障碍方法不是只判断“有没有风险”，而是判断“哪些速度和航向会导致风险”。

系统可以生成一组候选动作，例如：

```text
航向变化：-40°, -30°, -20°, -10°, 0°, +10°, +20°, +30°, +40°
速度比例：100%, 85%, 70%, 55%
```

每个候选动作都进行未来轨迹仿真，判断是否会带来碰撞风险。

候选动作评分函数可以写为：

```text
J(action) = w1 x future_collision_risk
          + w2 x route_deviation
          + w3 x maneuver_magnitude
          + w4 x speed_loss
          + w5 x rule_or_area_violation
```

其中：

- `future_collision_risk`：动作执行后的未来碰撞风险；
- `route_deviation`：偏离原航线的程度；
- `maneuver_magnitude`：转向或减速幅度；
- `speed_loss`：速度损失；
- `rule_or_area_violation`：是否违反规则或进入限制区域。

最终选择风险低、代价小、符合规则的候选方案。

## 15. 规则和区域约束

候选避碰动作不能只看数学分数，还要检查航海规则和空间约束。

至少需要检查：

- 是否进入禁航区或限航区；
- 是否偏离航道边界；
- 是否违反交通分离制方向；
- 是否使第三艘船风险升高；
- 是否超过船舶转向或减速能力；
- 是否与对遇、交叉、追越规则明显冲突。

因此，系统输出的不是“必须执行某动作”，而是“候选建议 + 风险解释 + 人工复核”。

## 16. 风险等级映射

可以把风险分为 5 个等级：

| 等级 | 含义 | 系统动作 |
|---|---|---|
| 0 | 正常 | 常态显示 |
| 1 | 关注 | 记录事件，轻提示 |
| 2 | 预警 | 显示会遇对象、DCPA/TCPA 和原因 |
| 3 | 高风险 | 高亮告警，生成候选避碰方案 |
| 4 | 紧急 | 紧急提示，要求人工立即处置 |

建议采用“硬条件 + 综合分”的方式：

```text
若 TCPA <= T_critical 且 DCPA <= D_critical：至少判为高风险
否则按 CRI、领域侵入程度和区域因素分级
若 AIS 数据过期：降低数据可信度，并提示人工核验
```

## 17. 怎么得出最终结果

对于一个船对，最终结果是这样得出的：

1. 获取两船最新 AIS 数据。
2. 检查数据时间戳、经纬度、SOG、COG 是否有效。
3. 将经纬度转换为局部平面坐标。
4. 将 SOG 和 COG 转换为速度向量。
5. 计算相对位置 `r` 和相对速度 `v`。
6. 计算 `TCPA` 和 `DCPA`。
7. 判断两船是否正在接近。
8. 识别会遇类型。
9. 计算 DCPA 风险隶属度 `μ_dcpa`。
10. 计算 TCPA 风险隶属度 `μ_tcpa`。
11. 计算区域和环境风险。
12. 计算 AIS 数据可信度。
13. 综合得到 `CRI`。
14. 根据 CRI 和硬阈值映射风险等级。
15. 如果风险较高，生成候选转向/减速动作。
16. 对每个候选动作做未来轨迹仿真。
17. 检查候选动作是否满足规则和区域约束。
18. 输出风险等级、原因解释和推荐候选方案。

输出示例：

```text
风险等级：高风险
风险分数：82/100
会遇类型：疑似交叉会遇
DCPA：280 m
TCPA：7.8 min
主要原因：DCPA 小、TCPA 短、两船正在接近
数据可信度：中
建议：人工复核；候选方案为右转 15° 或减速 20%
```

## 20. 验证方法

为了证明系统有效，不能只看地图演示，还需要进行历史 AIS 回放和人工复核。

推荐评价指标：

| 指标 | 含义 |
|---|---|
| Precision | 系统报警中人工确认有价值的比例 |
| Recall | 人工确认高风险事件中系统捕获的比例 |
| False Alarm Rate | 单位时间或单位船舶的误报数量 |
| Lead Time | 首次预警到最近会遇点的提前时间 |
| Review Acceptance Rate | 人工采纳候选建议的比例 |

验证流程：

1. 选择历史 AIS 高密度时段。
2. 回放船舶轨迹。
3. 系统自动计算风险事件。
4. 人工抽样复核高风险、低风险和临界案例。
5. 统计误报、漏报和提前预警时间。
6. 根据复核结果调整 CRI 权重和阈值。

## 21. 项目推进顺序

### 第一步：完成基础会遇风险计算

- AIS 数据清洗；
- 坐标转换；
- 邻近船筛选；
- CPA/TCPA 计算；
- 风险事件记录；
- 地图和列表展示。

### 第二步：加入风险分级

- 简化 CRI；
- 区域化阈值；
- AIS 数据可信度；
- 分级告警；
- 人工复核。

### 第三步：加入避碰决策支持

- 船舶领域；
- 候选转向/减速动作；
- 第三船风险检查；
- 规则和区域约束；
- 推荐前 2-3 个候选方案。

### 第四步：模型增强

- 用历史回放校准权重；
- 加入典型航线和交通流；
- 结合天气、潮流和能见度；
- 积累复核样本后做异常检测或轨迹预测。

## 22. 一句话总结

这个方案的算法可以概括为：

> 先根据 AIS 数据计算两船的相对运动，得到 DCPA 和 TCPA；再结合船舶领域、会遇类型、区域约束、环境因素和数据可信度计算碰撞风险指数 CRI；当风险较高时，枚举转向和减速候选动作，经过未来轨迹仿真和规则校验后，输出可解释的风险等级和避碰建议。

它最适合用于：

- 岸基 AIS 船舶碰撞风险预警；
- 马六甲海峡异常航行监测；
- 船舶会遇态势解释；
- 避碰决策支持；
- 历史 AIS 风险事件回放分析。

它不适合直接用于：

- 自动操控有人船；
- 单独判定法律责任；
- 仅凭 AIS 数据判断船舶违规或故意行为。
