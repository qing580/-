# 海上异常监测智能体任务8A实施计划（2026-09-22）

依据：`海上异常监测智能体任务8A离线基准集设计_2026-09-22.md`。

## 步骤1：确定性候选生成

1. 复用正式六小时AIS数据、现有事件算法、AIS工具、审核检索器和轻量图谱。
2. 按5分钟时间片生成会遇、行为变化、正常和证据不足候选。
3. 按事件过程、船舶组合、时间间隔和MMSI复用次数去重。
4. 固定选出2个正常、4个会遇、2个行为、3个证据不足和1个专业知识案例。

通过门槛：相同输入重复运行得到相同案例ID、MMSI、时间与证据ID。

## 步骤2：冻结证据与标注初稿

1. 为每例保存AIS上下文、检索结果和图谱路径。
2. 自动生成`draft`标注，列出必要证据、允许来源、结论边界和禁用陈述。
3. 生成数据集卡与逐例审核清单。
4. 将评测目录放在`运行结果`，不进入`知识库资料`。

通过门槛：12例均为`draft`，证据不包含回放时刻之后的数据，检索器不能命中评测目录。

## 步骤3：离线评分器

1. 检查结论边界、证据覆盖、AIS数值一致性、来源、禁用陈述和合理拒答。
2. 未经`approved`的案例默认拒绝正式评分。
3. 分项输出安全失败和未知证据，不用总分掩盖边界错误。

通过门槛：模拟正确回答、幻觉证据、未知来源、错误数值、违法认定和不合理拒答均能被区分。

## 步骤4：验证与交付

1. 运行任务8A新增测试和项目全量回归。
2. 复查12例配额、去重、证据时间边界和目录隔离。
3. 更新实施记录与根资料说明。
4. 把审核清单交给用户逐条确认；本轮不把案例改为`approved`。

本计划不包含真实DeepSeek调用、付费消融实验或论文最终统计结论。
