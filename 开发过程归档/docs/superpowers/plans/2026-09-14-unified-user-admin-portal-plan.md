# 用户端与管理端统一入口实施计划

日期：2026-09-14

## 实施顺序

1. 把当前用户端、管理端、启动脚本和相关说明复制到工作区，保留桌面项目原文件。
2. 新增统一入口 HTML、CSS、JavaScript，以两个常驻同源 iframe 承载现有两端。
3. 实现默认用户端、`#user/#admin` 地址状态、无刷新切换、各端状态保留、加载状态和单端重载。
4. 将管理端底图地址改为 OpenStreetMap 当前规范地址，并增加与用户端一致的加载失败提示。
5. 修改两个 PowerShell 启动脚本，使桌面快捷方式打开统一入口。
6. 新增统一入口自动化测试，运行用户端、管理端、会遇逻辑和统一入口测试。
7. 将验证通过的文件同步回桌面项目，更新统一入口使用说明、两端说明和项目资料索引。
8. 启动本地 HTTP 服务，用真实浏览器检查桌面与窄屏切换、状态保留、地图瓦片和主要业务页面。
9. 核对桌面快捷方式仍指向项目启动器，并实际验证一键启动统一入口。
