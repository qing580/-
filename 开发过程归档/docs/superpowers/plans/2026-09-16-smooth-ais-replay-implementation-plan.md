# 历史 AIS 双端平滑回放实施计划

日期：2026-09-16

## 目标

为用户端航行助手和管理端海事业务台接入同一套连续历史回放引擎，使船标平滑移动，同时保持真实轨迹、分类和风险证据只使用真实 AIS 观测。

## 任务 1：共享回放引擎

文件：

- 新增 `网页演示/Demo网页/共享组件/历史AIS回放引擎.js`
- 新增 `网页演示/Demo网页/共享组件/历史AIS回放引擎测试.cjs`

实现：数据校验和排序、二分查找、COG/SOG推算、真实点校正、长间隔降级、连续时钟、倍速和跳转。

验证：先写并运行纯逻辑测试，覆盖方向、节点对齐、缺失运动字段、长间隔、末尾外推和暂停/倍速。

## 任务 2：双端播放器集成

文件：

- 修改 `用户端航行助手版/用户端航行助手.html`
- 修改 `管理端海事业务台版/管理端海事业务台.html`

实现：加载共享引擎，以连续 `playbackTimeMs` 替换离散 `currentStep` 时钟；接入播放、暂停、30秒前后跳转、时间轴拖动和四档倍速。

兼容：保留 `currentTime()`、`activeVessels()` 和 `renderAll()` 的业务语义，确保现有用户端、管理端扩展脚本继续工作。

## 任务 3：地图增量更新

实现：

- marker 按 MMSI 缓存复用；
- 动画帧只更新可见船标坐标；
- 图标仅在航向、风险、类别或选中状态变化时更新；
- 真实轨迹按当前真实点索引更新；
- 拖动、倒退和筛选时允许重建轨迹；
- 删除每帧 `clearLayers()` 后重建全部地图对象的路径。

验证：记录同一 MMSI 的 marker 对象在多个动画帧中保持不变，并确认轨迹点数不包含估算点。

## 任务 4：业务刷新分层

实现：

- 动画帧：地图位置；
- 低频刷新：时间文本和状态；
- 每30秒历史边界：活动船、统计、列表、详情、CPA/TCPA、风险和告警；
- 显示风险快照时间和估算/陈旧状态；
- 陈旧船舶继续遵守5分钟风险新鲜度限制。

## 任务 5：自动化和浏览器验证

运行：

- 新共享引擎测试；
- 现有用户端、管理端、会遇和统一入口测试；
- 本地 HTTP 启动器。

浏览器验证：

- 桌面视口和窄屏视口；
- 用户端和管理端播放、暂停、继续、倍速、前后跳转、拖动；
- 连续采样船标像素或经纬度，证明位置连续变化；
- 地图瓦片非空、无403、控制台无错误；
- 双端切换后状态保留；
- 旧 Demo6、Demo7 和会遇专项文件哈希不变。
