# 双端功能分页面可视化实施计划

日期：2026-09-17

1. 在现有工作区副本上继续合并船舶图标、轨迹和防跨岸优化。
2. 新增共享原生 SVG 可视化组件与基础样式，不引入在线图表依赖。
3. 接入用户端：附近会遇、航线预评估、环境风险、智能问答与消息。
4. 接入管理端：异常事件中心、事件研判、船舶档案、环境监测、数据与模型。
5. 所有页面读取统一回放时间和当前对象，保留缺失值、单点和长断点语义。
6. 增加共享组件测试和双端接入测试，运行既有回放、会遇、用户端和管理端回归测试。
7. 启动本地页面，检查桌面与移动尺寸、页面切换和回放联动。
8. 测试通过后同步正式项目，更新实施记录和项目资料说明。
