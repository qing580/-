# 碰撞风险无分数分级设计

日期：2026-09-14

## 1. 背景与状态

当前用户端、管理端和会遇情景页面使用一个 0-100 的演示碰撞风险值。该值由 DCPA、TCPA、当前距离、航向夹角和 AIS 新鲜度加权得到。页面还同时存在船型分类置信度、AIS 字段完整率以及旧 AHP 综合风险分，多个数值容易被误认为可以直接比较。

旧评分法属于已完成的历史原型，不删除其代码和实验记录，但其权重和分段尚未经过专家判断或带真值事件校准，不能作为碰撞概率、法定风险标准或论文最终结论。

本设计已经用户确认，但尚未实现。阈值仍属于待验证设想。

## 2. 目标与非目标

目标：

- 当前演示中的碰撞风险彻底取消总分和 `/100` 表达。
- 用处置等级、原始运动学证据、会遇形态和数据状态表达筛查结果。
- 用户端、管理端、会遇动画、消息和事件详情采用一致语义。
- 保留旧方法记录，确保项目过程和论文复现不被篡改。
- 为后续动态船舶领域模型预留替换边界。

非目标：

- 不宣称当前规则等于 COLREGs 法定判定。
- 不输出自动转向、改速或避碰指令。
- 不把历史回放包装为实时监控。
- 本轮不训练新的碰撞风险模型，不声称提高预测准确率。

## 3. 方案选择

采用“处置等级 + 关键证据 + 数据可信状态”的证据式方案。

放弃两种备选：仅使用红黄绿会丢失判定依据；立即实现动态船舶领域模型需要更完整的尺度字段、专家边界和真值事件，当前证据不足。动态船舶领域作为后续验证方向，不作为本轮已完成能力。

## 4. 判定结构

碰撞风险模块改为规则判定器，不再输出用于展示或排序的总分。

输入包括两船当前距离、DCPA、TCPA、相对方位、航向差、速度、船舶尺度和 AIS 更新时间。处理顺序如下：

1. 检查数据有效性。
2. 计算当前距离和 CPA/TCPA。
3. 初筛对遇、交叉、追越或非明确会遇形态。
4. 按 DCPA/TCPA 二维规则确定处置等级。
5. 生成触发原因、数据状态和不确定性说明。
6. 按等级、TCPA、DCPA、当前距离进行确定性排序。

输出等级固定为：

- `立即核查`
- `重点关注`
- `持续观察`
- `当前无突出风险`
- `数据不足`

## 5. 暂定阈值

| 处置等级 | 暂定判定条件 |
| --- | --- |
| 立即核查 | `DCPA <= 0.5 nm` 且 `0 <= TCPA <= 10 min` |
| 重点关注 | `DCPA <= 1.0 nm` 且 `0 <= TCPA <= 20 min` |
| 持续观察 | `DCPA <= 1.5 nm` 且 `0 <= TCPA <= 30 min` |
| 当前无突出风险 | 不满足以上组合，或最近会遇点已在过去 |
| 数据不足 | 位置超时、关键运动字段缺失或相对速度过小导致 CPA 不稳定 |

这些数值是把当前 Demo 已使用的 `1.5 nm/30 min` 外层筛查范围拆成三级，属于项目暂定实验规则，尚未经过马六甲标注会遇事件、专家意见或敏感性分析验证。实现时集中保存在可配置对象中，不散落在界面代码中。

会遇形态只用于解释和同等级排序，不单独提升到最高等级。当前根据航向差得到的结果应称为“会遇形态初筛”，不能冒充完整 COLREGs 责任判断。

## 6. 数据异常与边界

- 任一位置记录超过 5 分钟时，不计算 CPA/TCPA，输出`数据不足`。
- 经纬度、SOG 或 COG 缺失或无效时，输出具体缺失原因。
- 相对速度过小时，标记 CPA/TCPA 不稳定，不强行给出等级。
- `TCPA < 0`表示最近会遇点已过，输出`当前无突出风险`并提示继续观察，不继续显示紧迫预警。
- 船长或船宽缺失时采用通用暂定阈值，并显示`船舶尺度缺失`。
- 历史数据页面必须显示`历史数据演示`。
- CPA/TCPA 基于匀速直线外推；目标转向、变速或 AIS 延迟均可能改变结果。

## 7. 页面设计

### 7.1 用户端

- 首页红色数字改为文字等级。
- 附近会遇列表展示等级、DCPA、TCPA 和会遇形态。
- 详情展示判定依据、更新时间、数据状态和人工核查提示。
- 消息列表不再显示碰撞风险分。

### 7.2 管理端

- Top 5 改名为`处置优先级`，不显示分数。
- 事件表的`风险分`列改为`处置等级`。
- 事件详情删除总分、权重和贡献条，展示规则触发链。
- 顶部统计展示各等级事件数量，不显示平均风险分。
- 行为异常事件在统一事件列表中同样使用处置标签和原始行为幅度，避免引入另一套无说明分数。

### 7.3 指标命名

船型分类置信度和 AIS 字段完整率可以继续使用百分比，但必须完整写成`船型分类置信度 82%`和`AIS 字段完整率 91%`。它们不得使用`风险分`名称。

## 8. 历史方法处理

旧 AHP 和加权碰撞风险值不删除。已有说明文档和运行结果保留原样，并追加状态说明：

- 已完成：加权风险原型和对应界面曾实现并通过当时的功能测试。
- 已知限制：权重与分段未经真实碰撞或近失事件真值验证。
- 当前决策：从活动演示和事件排序中撤下，不再作为当前碰撞预警输出。
- 待验证：动态船舶领域、尺度自适应阈值及马六甲样本校准。

## 9. 测试与验收

### 9.1 规则单元测试

- 覆盖三级阈值内、阈值边界和阈值外样本。
- 覆盖 `TCPA < 0`、AIS 超时、字段缺失和相对速度过小。
- 验证碰撞事件不再包含用于展示或排序的总分。
- 验证排序依次使用等级、有效正 TCPA、DCPA 和当前距离。

### 9.2 历史回放测试

- 使用现有六小时马六甲增强 AIS 数据。
- 统计各等级事件数量、船对数量和持续时间。
- 检查是否出现大面积、长时间最高等级预警。
- 抽查典型对遇、交叉、追越和已经驶离场景。
- 没有人工真值时只报告规则输出分布和案例审计，不报告碰撞预测准确率。

### 9.3 界面验收

- 用户端、管理端、会遇动画、消息和详情中不存在碰撞风险分及 `/100`。
- 百分比指标名称和单位明确。
- 桌面快捷方式仍打开统一入口，两端切换和回放状态保持正常。
- 完成桌面、1024 像素和 640 像素宽度检查，无文字重叠。
- 既有用户端、管理端和统一入口测试继续通过，并补充新规则测试。

## 10. 参考依据

- IMO, Convention on the International Regulations for Preventing Collisions at Sea, 1972, Rule 7。其核心要求之一是不能依据不足信息作出假设；本项目因此单独设置`数据不足`状态。
- Ha, Roh and Lee, 2021, *Quantitative calculation method of the collision risk for collision avoidance in ship navigation using the CPA and ship domain*, DOI: `10.1093/jcde/qwab021`。
- Liu et al., 2023, *A quantitative method for the analysis of ship collision risk using AIS data*, DOI: `10.1016/j.oceaneng.2023.113906`。

上述文献支持将 CPA/TCPA、船舶尺度、运动状态和船舶领域作为风险研判证据，但不直接证明本项目暂定阈值有效。

## 11. 实施边界

下一阶段只实施当前已确认的证据式分级和界面改造。动态船舶领域与阈值校准单独立项验证，避免将待验证研究方向提前包装为已完成功能。
