## 负责人结论

本次预检判定为：`PARTIAL_PASS_NOT_A_FIVE_CLASS_GOLD_LABEL_SOURCE`。

GFW Vessel API 可继续用于以下用途：

- MMSI、IMO、船名和登记记录的身份交叉核验；
- 渔船登记证据补充；
- 客船等类别的候选发现和人工复核线索。

GFW Vessel API 不适合作为当前五分类的唯一真值来源，原因是：

- 本批次没有获得任何集装箱船或散货船细分类；
- 本地 AIS 油轮样本在 GFW 当前记录中多显示为 `OTHER`；
- 多数可识别船型来自混合推断来源，而非独立登记真值。

因此暂不执行 1,499 艘全量 GFW 请求。继续全量调用只会增加查询量，并不能解决集装箱船/散货船标签缺失这一核心问题。

## 下一步

1. 将GFW定位为身份交叉核验和渔船补充来源，不把其混合推断字段直接写入五分类真值列。
2. 下一阶段针对集装箱船、散货船和油轮寻找可追溯的船舶登记/船队清单来源，先做小样本来源验证，再决定是否批量补全。
3. 现有货船/油轮二分类轨迹原型可继续推进，但五分类训练仍需等待细分类真值来源落实。
