本次整理日期：2026-10-10。本仓库是现有成果快照，不代表新增模型实验或效果验证完成。

开始时先看 `马六甲海峡实验/先看这里.md`。详细迁移和实验接续步骤在 `马六甲海峡实验/说明文档/跨电脑开发与实验交接说明_2026-10-09.md`。

## 新电脑启动

安装 Git 与 Node.js 24 系列，克隆后运行：

```powershell
git clone https://github.com/qing580/-.git maritime-anomaly-agent
Set-Location -LiteralPath '.\maritime-anomaly-agent\马六甲海峡实验'
node '.\源代码\智能问答服务\server.cjs' --port 8765
```

浏览器访问 `http://127.0.0.1:8765/`，保持服务窗口开启。端口占用时改成8766，并相应修改浏览器地址。默认本地证据模式，不自动开启真实大模型调用。

采集/分类实验另需 Python 环境；按照交接文档创建虚拟环境，先复现基线和验收数据。不要直接运行含旧电脑绝对路径的采集启动器、历史辅助脚本或桌面快捷方式。

## 数据与安全

AIS样本、审核资料和历史日志用于延续已有研究。第三方数据及资料仍受各自条款和来源约束，本次上传不授予额外再分发权或开源许可。

API Key、密码、环境文件、运行时缓存和虚拟环境不应提交。密钥在各电脑本地配置。真实在线调用前须核对官方接口与价格、确认预算；不要把私有资料、账号凭证或未获授权数据加入后续提交。

本仓库尚没有自动发布或桌面实时同步设置。每次开发后使用Git检查差异、提交并推送；另一台电脑先拉取再开发。不要让两台电脑同时覆盖同一批次、冻结标注或结果目录。
