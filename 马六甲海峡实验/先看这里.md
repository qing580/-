# 换电脑开发：先看这里

这个压缩包包含项目代码、AIS数据、已有实验结果、知识库和交接资料，不需要重新采集或从头开发。

## 只做三步

1. 将压缩包完整解压到固定位置，例如 `D:\科研`。不要直接在压缩包里打开HTML。
2. 安装 Node.js 24 系列；要跑采集/分类实验，再安装 Python 3.11或3.12。
3. 打开PowerShell，执行下列命令，第一行替换为实际解压路径：

```powershell
Set-Location -LiteralPath 'D:\科研\马六甲海峡实验'
node '.\源代码\智能问答服务\server.cjs' --port 8765
```

保持窗口开启，在浏览器打开 `http://127.0.0.1:8765/`，即可使用现有用户端和管理端。停止服务按Ctrl+C。端口占用时换成8766，浏览器地址也一起改。

## 继续开发时

把解压后的“马六甲海峡实验”文件夹作为开发项目打开，对开发助手说：

> 请先阅读根目录《马六甲海峡实验资料说明.md》和《说明文档/跨电脑开发与实验交接说明_2026-10-09.md》。先验收现有功能，再接着已有成果开发，不从头重做。区分已完成实验和待验证设想；先核对CASE-ENCOUNTER-002正式与暂存审核状态差异。资料和代码都保存在当前项目内，不自动开启付费模型或长时间采集。

Python环境、采集、实验复现、测试和桌面图标配置，都在完整交接文档中；用到时再看，不用一次全部操作。

注意：旧桌面快捷方式不能直接搬用；旧采集启动器含原电脑路径，不能照搬。当前默认离线证据模式，不代表已验证大模型效果或五分类准确率。包内有项目研究数据与日志，请私下传给自己的另一台电脑，不要直接公开上传。
