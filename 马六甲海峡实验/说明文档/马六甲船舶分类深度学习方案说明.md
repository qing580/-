# 马六甲海峡船舶分类深度学习方案说明

## 1. 建设目标

在已有 AIS 船舶分类 Demo 的基础上，增加一个深度学习辅助分类分支。该分支不直接替代 AIS 船型码规则，而是作为补充判断：

- 当 AIS 船型码明确时，规则分类作为主判断；
- 当 AIS 船型码缺失或船舶被标为“未知”时，深度学习模型根据轨迹行为给出补充分类；
- 当规则分类和模型分类冲突时，系统提示“建议人工复核”；
- 最终在 Demo 详情页展示“规则分类、深度学习分类、置信度、融合结论”。

## 2. 推荐模型结构

正式模型推荐采用 `1D-CNN + BiLSTM + Attention`：

```text
AIS轨迹序列
  -> 数据清洗与轨迹切片
  -> 1D-CNN提取局部运动模式
  -> BiLSTM学习前后时序变化
  -> Attention突出关键轨迹片段
  -> Softmax输出船型概率
```

推荐输入特征：

- `lat`：纬度
- `lon`：经度
- `sog`：对地航速
- `cog`：对地航向
- `heading`：船首向
- `rate_of_turn`：转向率
- `time_delta`：相邻 AIS 点时间间隔
- `delta_lat / delta_lon`：位置变化
- `delta_sog / delta_cog`：速度与航向变化

推荐输出类别：

- 货船
- 油轮
- 渔船
- 客船
- 拖船/港口服务船
- 高速船
- 作业船
- 其他

由于本机环境暂未安装 PyTorch/TensorFlow，当前先实现了一个可运行的弱监督神经网络原型：

- 脚本：`src/features/deep_vessel_classifier.py`

- 模型：NumPy 单隐藏层 MLP
- 训练标签：现有规则分类结果作为弱标签
- 作用：为 Demo 提供“深度学习分类结果、置信度、融合结论”

同时保留正式 PyTorch 模型结构：

- 脚本：`src/features/deep_sequence_model_pytorch.py`
- 模型：`VesselSequenceClassifier`
- 结构：1D-CNN + BiLSTM + Attention

## 4. 融合分类逻辑

系统不盲目相信单一模型，而采用融合策略：

```text
如果规则分类明确，且深度学习结果一致：
    输出该类别，标记“规则与模型一致”

如果规则分类明确，但深度学习结果冲突：
    保留规则分类，标记“建议人工复核”

如果规则分类未知，但深度学习置信度 >= 60%：
    使用深度学习结果作为补充分类，标记“建议人工确认”

如果深度学习置信度 < 60%：
    保持未知或原规则分类，标记“建议人工复核”
```

这样做的优点是稳妥：既体现深度学习，又避免在数据不足时过度承诺。

## 5. Demo 展示方式

点击某艘船进入单船详情页后，报告中新增：

- 规则分类结果
- 深度学习分类结果
- 深度学习置信度
- 融合分类结论
- 是否建议人工复核

在 LangGraph 智能体流程中，`节点2 船舶分类` 会展示规则分类和深度学习分类的联合判断。

## 6. 当前局限

当前一小时 AIS 数据中，带有明确静态船型信息的样本有限，且渔船、客船等类别样本不足。因此当前模型只能作为“演示型弱监督原型”，不能直接宣称为高精度最终模型。

后续需要继续采集更多 AIS 数据，并补充人工标注表，才能训练更可靠的深度学习模型。

## 7. 后续升级路线

1. 继续采集马六甲海峡 AIS 数据，建议至少 6-24 小时；
2. 使用人工补全表补充船名、船型、MMSI 对应关系；
3. 将每艘船轨迹切成固定长度序列，例如 20 点或 50 点；
4. 安装 PyTorch，训练 `1D-CNN + BiLSTM + Attention`；
5. 输出混淆矩阵、Accuracy、Precision、Recall、F1-score；
6. 将训练好的模型结果接入 Demo。
