# 历史 AIS 数据源与开源项目调研

日期：2026-09-08。状态：已下载 NOAA 历史 AIS 日文件，并完成纽约港与休斯敦/墨西哥湾两个区域的字段映射和消融试跑。

## 结论

可以找历史 AIS 数据来验证船舶分类功能，且比继续等待实时 AIS 更适合作为论文实验的可复现验证。

优先路线不是直接依赖 GitHub 上别人整理过的小样本，而是优先使用 NOAA MarineCadastre 的公开历史 AIS 数据；GitHub 项目主要用于借鉴预处理、轨迹重采样、特征工程和评估写法。

本轮已经完成一次实际试跑：NOAA 2023-01-01 全国 AIS ZIP 下载成功，转换出纽约港和休斯敦/墨西哥湾两个 6 小时样本。纽约港样本货船/油轮不均衡，不适合判断；休斯敦/墨西哥湾样本可用，外部历史数据上也能看到增强特征方向优于旧轨迹特征。

## 候选数据源

### NOAA MarineCadastre AIS

官网数据页：`https://marinecadastre.gov/ais/`

该数据源提供美国水域历史 AIS 数据，时间覆盖到 2009 至 2025 年。下载格式包括 FileGDB、CSV、GeoPackage 和 SQLite。虽然区域不是马六甲海峡，但字段公开、可复现、适合验证“六小时轨迹 + 静态字段是否提高分类准确度”这个方法问题。

字段参考页：`https://www.fisheries.noaa.gov/inport/item/69515`

字段包含 MMSI、BaseDateTime、LAT、LON、SOG、COG、Heading、VesselName、IMO、CallSign、VesselType、Status、Length、Width、Draft、Cargo、TransceiverClass 等。对船舶分类而言，核心字段较全。

GitHub 批处理工具：`https://github.com/ocm-marinecadastre/ais-vessel-traffic`

该仓库是官方相关的批量下载与处理入口，可用于自动下载指定日期/区域的 AIS 文件。

### Danish Maritime Authority AIS

数据页：`https://dma.dk/safety-at-sea/navigational-information/ais-data`

丹麦海事局提供丹麦水域历史 AIS CSV，可按日期下载。该数据源适合做公开历史数据的补充验证，但区域与马六甲海峡不同；如果使用，只能验证方法稳定性，不能证明马六甲区域业务结论。

### GitHub 开源项目

示例：`https://github.com/125ade/AIS_Data_Analysis`

这类项目可借鉴轨迹清洗、可视化、聚类和异常检测流程，但通常不能直接作为论文数据源。原因是数据来源、字段含义、许可和标签质量不一定清楚。

## 和当前项目的关系

当前马六甲增强 AIS 数据已经证明采集字段方向有价值：静态字段和空间/轨迹特征能够提高货船/油轮弱标签分类效果。但它仍有三个风险：

1. 样本只有 144 艘货船/油轮候选。
2. 标签来自 AIS 自报 `vessel_type`，没有外部核验。
3. 空间特征可能学到 2026-09-08 这 6 小时的区域分布。

历史 AIS 数据的作用不是替代马六甲数据，而是做方法验证和稳定性对照：如果在 NOAA 历史数据上也能看到“动态 + 静态 + 空间特征”优于旧轨迹特征，则说明方法方向更可靠；如果外部历史数据上不提升，要重新检查当前数据是否只是偶然或区域偏差。

## 推荐执行方案

1. 已下载 NOAA MarineCadastre `AIS_2023_01_01.zip`。
2. 已保留与当前脚本兼容的字段：MMSI、时间、经纬度、SOG、COG、Heading、Status、VesselType、Length、Width、Draft。

5. 与马六甲 2026-09-08 结果对比时，只比较方向是否一致，不把不同海域准确率直接横向写成同一个结论。

## 已完成实测

### 纽约港样本

输出数据：`原始数据/NOAA_MarineCadastre/noaa_nyharbor_ais_6h_2023-01-01.csv`。

筛选得到 55881 行、293 艘船，293 艘都有 `VesselType`。但货船/油轮候选只有 28 艘，其中货船 25 艘、油轮 3 艘。该样本类别严重不均衡，不能用于判断货船/油轮分类方法优劣。保留为字段映射试运行，不作为模型结论。

### 休斯敦/墨西哥湾样本

输出数据：`原始数据/NOAA_MarineCadastre/noaa_houston_gulf_ais_6h_2023-01-01.csv`。

筛选得到 160000 行、1025 艘船，其中 1023 艘有 `VesselType`。货船/油轮候选 224 艘，其中货船 79 艘、油轮 145 艘。结果目录为 `运行结果/NOAA休斯敦历史AIS特征消融_2023-01-01_6h`。

固定划分上，C 组逻辑回归测试准确率 66.67%，宏 F1 为 0.5620；旧特征组 A 的逻辑回归宏 F1 为 0.3919。30 次重复划分中，C 组逻辑回归宏 F1 均值 0.6124，旧特征组 A 逻辑回归宏 F1 均值 0.3918。

保守解释：外部历史 AIS 上也支持“动态 + 静态 + 空间特征”比旧轨迹特征更有用，但休斯敦样本仍有油轮偏多问题，货船召回还不够强，不能直接作为最终论文准确率。

## 保守判断

能做，而且已经跑通。实时 AIS 适合补马六甲本地场景，历史 AIS 适合做方法复现和压力测试。下一步应继续用 NOAA 历史 AIS 找一个货船/油轮更均衡的港区或日期，再做封存式验证；不要继续盲目等实时采集。
