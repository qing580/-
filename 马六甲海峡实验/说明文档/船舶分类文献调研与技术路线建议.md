# 马六甲海峡 AIS 船舶分类文献调研与技术路线建议

## 一、当前分类效果不理想的原因

当前 Demo 中船舶分类结果“不如人意”，主要不是单纯代码问题，而是由 AIS 数据特点和当前方法共同造成的。

1. **AIS 静态信息缺失**  
   当前分类主要依赖 `vessel_type`、`vessel_name` 等静态字段。如果采集时只收到 `PositionReport`，没有收到 `ShipStaticData`，系统就缺少船型码、船名、IMO、呼号等关键信息，容易被归为“未知”。

2. **采集时间偏短**  
   1 小时 AIS 数据可以看到较多位置点，但不一定能收到每艘船的静态信息。采集 6 小时、12 小时或更长时间，可以增加收到静态船型信息的概率，也能让同一艘船形成更完整的轨迹序列。

3. **规则分类技术含量有限**  
   只使用 AIS 船型码映射，属于规则法。优点是稳定、可解释，缺点是遇到缺失值时能力弱，难以体现机器学习或深度学习创新。

4. **样本类别不平衡**  
   马六甲海峡附近货船、油轮数量较多，渔船、客船、特殊作业船样本可能较少。深度学习模型如果没有足够样本，也很难学到少数类特征。

## 二、调研方向划分

根据 AIS 船舶分类研究，相关方法大致可以分为五类：

1. **基于 AIS 船型码的规则分类**  
   适合做基线，但创新性弱。

2. **基于人工特征的传统机器学习分类**  
   如 Random Forest、SVM、XGBoost、LightGBM，输入平均速度、航向变化、轨迹长度、停留比例等统计特征。

3. **基于 AIS 轨迹序列的深度学习分类**  
   如 1D-CNN、LSTM、GRU、TCN、Transformer，输入连续 AIS 点，学习船舶运动模式。

4. **基于轨迹图像的船型识别**  
   将船舶轨迹绘制成图像，使用 CNN 识别轨迹形态。

5. **多源融合与主动学习方法**  
   融合规则分类、轨迹序列模型、轨迹图像模型、人工补全表和知识库，重点解决 AIS 静态信息缺失问题。

## 四、可选技术路线比较

### 方案 A：传统机器学习增强版

结构：

```text
AIS数据 -> 轨迹统计特征 -> Random Forest / XGBoost / LightGBM -> 船型分类
```

优点：

- 数据量要求较低；
- 训练速度快；
- 特征重要性好解释；
- 适合作为论文基线模型。

缺点：

- 创新性一般；
- 对轨迹时间顺序利用不足。

适合用途：

- 做对比实验；
- 证明机器学习优于单纯规则法。

### 方案 B：轨迹序列深度学习模型

结构：

```text
AIS轨迹序列 -> 1D-CNN / BiLSTM / TCN / Transformer -> 船型分类
```

优点：

- 技术含量更高；
- 能学习速度、航向、位置变化的时序模式；
- 与现有 AIS 字段匹配。

缺点：

- 需要更多样本；
- 类别不平衡会影响效果；
- 训练和调参成本更高。

适合用途：

- 作为核心深度学习模型；
- 在 Demo 中展示“深度学习分类置信度”。

### 方案 C：多源融合创新方案

结构：

```text
AIS静态信息
  + AIS轨迹序列
  + 轨迹图像
  + 人工补全表
  + 船舶知识库
  -> 融合分类器
  -> 低置信度样本主动学习
```

优点：

- 创新点最强；
- 能解释为什么比规则法更好；
- 适合解决“静态信息缺失导致未知船多”的问题；
- 与 AISFusionNet、多模型集成、主动学习等文献方向一致。

缺点：

- 完整实现复杂；
- 初期需要先做简化版。

适合用途：

- 作为项目最终技术路线；
- 答辩和论文写作最有说服力。

## 五、推荐最终技术路线

推荐采用 **方案 C 的简化落地版**：

```text
AIS原始数据
  -> 数据清洗与轨迹切片
  -> 规则分类器：利用 AIS vessel_type / 船名关键词
  -> 轨迹统计特征模型：LightGBM 或 Random Forest
  -> 轨迹序列深度学习模型：1D-CNN + BiLSTM + Attention
  -> 轨迹图像辅助分支：将轨迹转为小图，用 CNN 提取形态特征
  -> 融合决策模块：规则结果 + ML结果 + DL结果
  -> 主动学习模块：低置信度/冲突样本进入人工补全表
  -> Demo 展示：规则分类、模型分类、融合分类、置信度、人工复核建议
```

这个路线可以命名为：

**面向 AIS 静态信息缺失场景的多源融合船舶分类方法**

## 六、创新点表达

可以在开题/中期/答辩中这样表达：

1. **针对 AIS 静态信息缺失问题**  
   传统规则法依赖 `vessel_type`，一旦缺失就难以分类。本项目引入轨迹行为特征和深度学习模型，提高未知船舶的可识别性。

2. **序列特征与图像特征融合**  
   不仅把 AIS 当表格数据处理，还将轨迹转为图像，结合序列模型和图像模型共同识别船型。

3. **规则分类与学习模型融合**  
   规则法负责高可信静态船型码，机器学习负责轨迹统计特征，深度学习负责复杂时序模式，融合后比单一方法更稳健。

4. **主动学习人工补全机制**  
   对低置信度和模型冲突样本自动生成人工复核表，让系统随着后续数据采集不断改进。

## 七、近期落地步骤

第一阶段不直接做很大的模型，先做可验证版本：

1. 继续采集 6 小时 AIS 数据；
2. 生成船舶轨迹统计特征表；
3. 建立规则分类基线；
4. 建立传统机器学习基线；
5. 建立 1D-CNN + BiLSTM + Attention 原型；
6. 对比规则法、机器学习法、深度学习法的分类结果；
7. 将融合分类结果接入 Demo；
8. 对低置信度样本生成待人工补全表。

第二阶段再扩展：

1. 加入轨迹图像分支；
2. 增加主动学习循环；
3. 写实验对比表和消融实验；
4. 形成论文式技术路线图。
