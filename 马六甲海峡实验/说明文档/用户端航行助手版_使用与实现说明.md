# 用户端航行助手版使用与实现说明

更新时间：2026-09-14

## 1. 演示入口

优先双击桌面的 `海上异常监测智能体` 图标打开统一入口，再选择顶部的 `航行助手`。桌面图标是快捷方式，实际代码、HTML、启动脚本和图标资源仍保存在 `马六甲海峡实验` 项目文件夹中；后续更新本页面后，无需重新制作桌面图标。

也可以双击上一级 `Demo网页/启动用户端航行助手.cmd` 打开。启动窗口会建立本地 HTTP 服务并自动打开用户端页面；演示期间请保留该窗口，按 `Ctrl+C` 可停止服务。不要再直接双击 `用户端航行助手.html`，因为 `file://` 页面缺少 OpenStreetMap 瓦片服务要求的有效 Referer，可能显示 403 拦截图。

AIS 数据已经嵌入 HTML；Leaflet、OpenStreetMap 底图和 Lucide 图标仍需要联网加载。页面使用官方当前瓦片地址并保留可见署名；底图加载失败时会显示状态提示，但船舶数据与风险计算仍可使用。

## 2. 产品定位

用户端面向船公司调度人员、船舶驾驶员和航运服务人员，重点回答“我的关注船现在需要注意什么”。本版本提供风险辅助提示，不是监管派单系统，不提供自动驾驶、法定避碰决策或安全保证。

## 3. 已实现功能

1. **航行首页**：默认定位到六小时数据中段；可切换关注船；地图突出关注船、弱化无关目标；展示相关 Top 5 会遇和三条简短提示。
2. **附近会遇**：只保留与关注船有关的双船 CPA/TCPA 事件，显示当前距离、DCPA、TCPA、会遇形态、AIS 可信提示和风险原因。
3. **航线预评估**：输入目的地、预计航速和走廊宽度，筛查当前事件与直线走廊的空间接近关系。
4. **环境风险**：当前没有可靠环境数据时显示未覆盖状态，不伪造台风、风浪、海流、赤潮或油膜结果。
5. **智能问答与消息**：提供三个引导问题；回答包含结论、数据时间、证据、可信提示、不确定因素和下一步动作；风险消息可点击查看依据并在当前会话标记已读。

## 4. 数据和算法边界

- 数据来自六小时增强 AIS 批次，共 581 个有效 MMSI、15414 条有效位置记录。
- 当前为历史数据回放，不是实时在线监测。默认从数据中段开始，用户仍可拖动时间轴查看完整六小时。
- 活跃目标要求位置时间距当前回放时刻不超过 5 分钟。
- 附近会遇使用 CPA/TCPA 匀速直线外推；只显示双船会遇事件，不把单船异常转向或异常减速混作“附近船舶”。
- 航线页只计算事件与起终点直线走廊的距离，没有检查水深、陆地、交通分离制、禁限区、船舶操纵性或环境影响，因此不是可航路线。
- 智能问答当前是本地证据模板，在线大模型尚未接入。
- 环境数据尚未接入，不能形成环境综合风险结论。

## 5. 主要文件

- `用户端航行助手.html`：用户端入口与嵌入 AIS 数据。
- `../启动用户端航行助手.cmd`、`../start_navigation_assistant.ps1`：本地 HTTP 一键启动入口。
- `../启动资源/`：桌面快捷方式使用的原图、透明 PNG、多尺寸 ICO 和图标生成脚本。
- `用户端界面.css`、`用户端界面.js`：五页界面、地图、导航和交互。
- `用户端数据逻辑.js`：关注船事件筛选、风险摘要、路线走廊和问答结构。
- `管理端数据逻辑.js`：AIS 快照、CPA/TCPA 事件与数据质量逻辑。
- `船舶邻近计算.js`：距离、CPA/TCPA 和风险值计算。
- `用户端功能测试.cjs`、`会遇功能测试.cjs`：自动化逻辑测试。

## 6. 验证结果

2026-09-09 已完成用户端 7 项测试与会遇计算 15 项测试，共 22 项通过；真实浏览器检查覆盖航行首页、附近会遇、会遇详情、航线表单与结果、环境空状态、问答六项字段、消息跳转、关注船切换和 1024×768 窄屏布局。

2026-09-14 纳入统一入口后再次运行上述 22 项测试，全部通过；真实浏览器切换后关注船与回放状态能够保留。
