## 安全与合规设计

- API Token 仅从 `GFW_API_TOKEN` 读取；启动器采用隐藏输入并在子进程结束后清除环境变量。
- 默认模式只准备样本，必须显式增加 `-Execute` 才会联网。
- 使用官方 Vessel API v3 和 `public-global-vessel-identity:latest` 数据集。
- 原始响应逐查询保存，重复运行优先使用缓存。
- 保留数据集实际版本和 API 限额响应头。
- 研究用途必须遵守非商业、Token 保密和来源署名要求。

## 错误处理

- `401` 归为认证失败并立即停止。
- `403` 归为权限不足并立即停止。
- `429` 和服务端 `5xx` 允许有限次数指数退避。
- 网络错误、解析错误、请求成功但无结果分别记录。
- 不将无结果写成“未知标签”，也不将宽泛 `cargo` 自动拆成集装箱船或散货船。
