## 1. 改版目标

以现有“会遇情景演示版”为数据和算法基础，新增独立的“管理端海事业务台版”。新版不覆盖、不删除旧版，重点解决当前页面信息拥挤、主次不清、只有地图而缺少业务闭环的问题。

管理端面向海事监管、港口调度和应急管理演示，核心任务是形成：

`发现异常 -> 初步研判 -> 查看证据 -> 状态流转 -> 记录处置 -> 关闭或标记证据不足`

系统只提供风险辅助研判，不宣称自动避碰、法定航行决策或安全保证。

## 2. 已确定的视觉方向

采用“A1 海事业务台”风格：

- 浅灰中性页面背景，白色工作区域，深海绿色侧边导航。
- 青色表示数据接入、运行和普通交互状态。
- 红色只用于高风险、紧急事件和超时事项。
- 黄色用于中等关注、待确认或数据质量提醒。
- 地图为首页主视图，右侧仅显示 Top 5 紧急事件，避免浮层互相遮挡。
- 卡片圆角不超过 8px，紧凑排布，强调监管业务工具感。

## 3. 页面与职责

### 3.1 综合态势

- 在线 Leaflet/OpenStreetMap 地图。
- 六小时增强 AIS 历史数据回放、播放/暂停、时间滑块和倍率控制。
- 船型、风险等级、数据质量筛选。
- 当前船舶、高风险会遇、待核查事件、AIS 有效率四个关键指标。
- 右侧 Top 5 紧急事件，按风险值和 TCPA 紧迫度排序。
- 点击船舶进入船舶档案；点击事件进入事件研判。
- “高风险聚焦”只保留高风险目标并定位最紧急事件。

### 3.2 异常事件中心

- 事件字段：编号、类型、首次发现时间、更新时间、位置、涉及船舶、风险等级、置信度/算法可用性、数据源、处理人、处置时限和状态。
- 首版事件类型重点支持高风险会遇、异常转向、异常减速、AIS 中断或数据质量异常。
- 状态流转：待确认、待核查、已派单、处理中、已确认、已关闭、误报或证据不足。
- 状态操作仅作为前端演示状态，刷新后可恢复初始演示数据；界面必须注明尚未接入真实后端工单系统。

### 3.3 事件研判与证据链

- 事件摘要：时间、地点、类型、风险等级和涉及目标。
- 会遇证据：当前距离、DCPA、TCPA、相对航向、AIS 新鲜度。
- 风险值分解：DCPA 38%、TCPA 28%、当前距离 18%、航向夹角 10%、AIS 新鲜度 6%。
- 明确显示风险分段和各项贡献，不把演示综合分包装为行业法定标准。
- 展示数据时间、算法版本、输入缺失项和不确定因素。
- 提供“播放会遇情景”按钮调用已有碰撞动画，不再强制每次点击船舶播放。
- 提供人工核查建议和事件状态操作。

### 3.4 船舶档案

- 船名、MMSI、IMO、呼号、尺寸和吃水。
- AIS 静态船型、模型推断船型、置信度、融合结论和人工核验状态分别展示。
- 当前经纬度、速度、航向、数据时间和位置点数量。
- 六小时数据中的活动时间范围、速度统计、历史会遇风险和数据缺失提示。
- 未经训练验证的模型显示“待训练/待验证”，不生成虚假预测值。

### 3.5 环境监测

- 为台风、风、浪、流、海温、叶绿素异常、赤潮疑似和油膜疑似预留图层入口。
- 当前没有可靠环境数据时，明确显示“数据暂未接入”，并列出所需来源和时间字段。
- 不以模拟图层冒充马六甲海峡实测或实时环境数据。

### 3.6 数据与模型管理

- AIS 数据源、时间范围、记录数、船舶数、更新时间、字段缺失率和位置有效率。
- CPA/TCPA 算法版本、计算前提、不可计算原因和适用边界。
- 船舶分类模型当前状态、训练/验证/封存测试集状态和人工核验覆盖率。
- 已知局限：六小时样本、AIS 静态标签噪声、低速目标航向不稳定、匀速直线外推假设和环境数据尚未接入。

## 4. 导航与交互

- 左侧固定导航在六个页面之间切换，当前页面有清晰选中状态。
- 页面跳转采用前端视图路由，不重新载入约 2.5 MB 的内嵌 AIS 数据。
- 点击地图船舶时图标放大，并进入对应船舶档案。
- 点击 Top 5 事件或事件表格行时进入事件研判页。
- 研判页提供返回事件中心和返回综合态势两个明确入口。
- 筛选、回放时间和当前选中目标在页面切换后保持。
- 移动端改为顶部菜单，事件列表放在地图下方，避免浮层遮挡地图。

## 5. 数据流与计算边界

主要数据流：

`六小时增强 AIS -> 时间索引 -> 每船当前状态 -> 船对邻近筛选 -> CPA/TCPA -> 风险值 -> 事件生成 -> Top 5 排序 -> 证据链`

- 数据源继续使用 `malacca_enhanced_ais_6h_2026-09-08_123520_473.csv` 同步生成的数据对象。
- 当前帧只使用播放时间之前的最新有效位置。
- CPA/TCPA 继续复用已测试的 `船舶邻近计算.js`。
- 船型优先展示 AIS `vessel_type` 映射结果；深度学习分类结果只有在真实训练和验证完成后才接入。
- 大模型/智能体只负责证据整理、自然语言解释和核查建议，不替代 CPA/TCPA 数值计算与轨迹分类模型。

## 6. 异常与空状态

- 在线地图失败：显示地图加载失败提示，其他业务页面仍可访问。
- AIS 位置过旧：显示数据延迟标记，并降低结果可信提示。
- SOG/COG 缺失、COG 无效、速度过低或相对速度过小：CPA/TCPA 显示“不可计算”及具体原因。
- 没有满足条件的风险目标：Top 5 区域显示空状态，不生成虚假事件。
- 环境数据未接入：显示未覆盖状态、所需字段和接入计划。
- 模型尚未训练：显示待训练，不给出模型类别或置信度。
