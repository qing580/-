# 船舶分类深度学习相关项目与文献资料

## 一、GitHub 参考项目

### 1. GlobalFishingWatch/vessel-classification

链接：https://github.com/GlobalFishingWatch/vessel-classification

可借鉴点：

- 使用 AIS/VMS 数据进行船舶类型识别；
- 采用 1D CNN 从 AIS 时间序列中提取船舶行为特征；
- 输出船舶类别、船长等属性；
- 项目来自 Global Fishing Watch，和真实海事监管场景关联强。

对本项目的启发：

本项目可以借鉴其“从 AIS 轨迹中提取行为模式，再用神经网络进行船型识别”的路线。由于当前数据量较小，本项目先采用轻量弱监督原型，后续再升级为 1D CNN 或 CNN-LSTM。

### 2. hoyon-lab/AIS_tracking

链接：https://github.com/hoyon-lab/AIS_tracking

可借鉴点：

- 支持 CNN-LSTM、TCN、Attention TCN、TCN-Transformer 等模型；
- 输入字段包括 `LAT, LON, SOG, COG, Heading`，和本项目 AIS 字段高度一致；
- 同时包含船舶分类和异常检测两类任务；
- 支持混淆矩阵、t-SNE、模型对比等评价方式。

对本项目的启发：

本项目可以先使用 CNN-LSTM/BiLSTM-Attention 做船舶分类，后续再扩展到 TCN 或 Transformer。

### 3. destiny1103/GIN-Ship-type

链接：https://github.com/destiny1103/GIN-Ship-type

可借鉴点：

- 使用 AIS 轨迹数据做船型识别；
- 类别包括 Cargo、Tanker、Passenger、Tug、Fishing、Pleasure；
- 对类别不平衡问题有参考价值；
- 使用图表示学习思想，将轨迹构造成图结构。

对本项目的启发：

后续如果要做更高级版本，可以把船舶轨迹或船舶之间的邻近关系建成图，再进行船型识别或风险传播分析。

## 二、论文参考

### 1. Ship Classification Based on AIS Data and Machine Learning Methods

链接：https://www.mdpi.com/2079-9292/13/1/98

关键信息：

- AIS 船型码可以区分渔船、拖船、客船、货船、油轮等粗类别；
- 船型分类可结合船舶几何特征和轨迹行为特征；
- 轨迹行为特征包括经纬度、速度、航向、转向率等；
- 论文使用 Accuracy、Precision、Recall、F1-score 评价分类效果。

对本项目的支撑：

本项目选择 `lat, lon, sog, cog, heading, rate_of_turn` 等字段作为深度学习输入，是有文献依据的。

### 2. AISFusionNet: A dual-branch fusion network for robust and intelligent ship type classification

链接：https://www.sciencedirect.com/science/article/pii/S0029801826026569

关键信息：

- 提出 AIS 时间序列与轨迹图像融合的双分支船舶分类框架；
- 时间序列分支可学习船舶运动行为；
- 轨迹图像分支可学习轨迹空间形态；
- 说明仅依赖单一数据源在复杂环境下鲁棒性不足。

对本项目的支撑：

本项目当前先做 AIS 时间序列分类，后续可扩展为“轨迹序列 + 轨迹图像”的双分支模型。

### 3. AIS data-based ship trajectory prediction using a CNN-Transformer-MLP hybrid model

链接：https://doi.org/10.1016/j.oceaneng.2026.126028

关键信息：

- 使用 CNN、Transformer、MLP 组合建模 AIS 轨迹；
- CNN 提取局部运动模式；
- Transformer 建模长时序依赖；
- K-means 聚类用于增强航行行为特征。

对本项目的支撑：

虽然该论文主要做轨迹预测，但它证明 CNN/Transformer 可用于 AIS 时序行为建模，为本项目后续升级模型提供依据。

## 三、本项目采用的技术路线依据

结合上述项目和论文，本项目采用以下路线：

```text
AIS轨迹数据
  -> 轨迹清洗和特征提取
  -> 规则分类器获得基础标签
  -> 深度学习模型学习轨迹行为
  -> 输出类别概率和置信度
  -> 与规则分类结果融合
  -> Demo详情页展示智能体分类结论
```

该路线的合理性在于：

- AIS 船型码可以提供基础类别，但存在缺失和不完整问题；
- 轨迹行为特征能够补充船舶类别识别；
- 深度学习适合学习复杂时序运动模式；
- 规则分类和模型分类融合，比单独使用模型更稳健。
