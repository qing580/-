# 船舶分类功能说明

## 目标

船舶分类模块用于把 AIS 数据中的船舶分成货船、油轮、渔船、其他和未知。分类结果会服务后续异常检测，因为不同船型的正常行为不一样。

## 分类优先级

1. AIS 原始数据中有 `vessel_type`：直接按 AIS 船型码分类。
2. AIS 中没有 `vessel_type`：按 MMSI 查询 `data_processed/vessel_registry.csv` 人工补全表。
3. 补全表也没有：用船名关键词做辅助判断。
4. 信息仍不足：标记为未知，并要求人工复核。

## 船型码规则

- `30`：渔船
- `70-79`：货船
- `80-89`：油轮
- 其他类型码：其他
- 缺少类型码：未知

## 人工补全表字段

`data_processed/vessel_registry.csv` 包含：

- `mmsi`：船舶唯一编号
- `vessel_name`：船名
- `vessel_type`：AIS 船型码
- `category`：货船、油轮、渔船、其他、未知
- `source`：信息来源，例如 AISStream、VesselFinder、MarineTraffic、人工查询
- `verified`：是否确认，建议填写 yes/no
- `remark`：备注
- `updated_at`：更新日期

## 使用命令

```powershell
python src/features/classify_vessels.py --input data_raw/ais_malacca_test.csv --registry data_processed/vessel_registry.csv --output results/tables/malacca_vessel_classification_test.csv
```

## 如何补全数据

打开公开船舶查询网站，输入 MMSI，查到船名和船型后填入 `vessel_registry.csv`。例如：

```text
mmsi,vessel_name,vessel_type,category,source,verified,remark,updated_at
525901612,EXAMPLE CARGO,70,货船,VesselFinder,yes,人工查询确认,2026-09-01
```
