# 马六甲海峡风险等级预测深度学习模型说明

## 1. 模型定位

本模型是第二个深度学习模块，和船舶分类模型不同。

船舶分类模型回答：

```text
这艘船是什么类型？
```

风险等级预测模型回答：

```text
这艘船当前危险程度是多少？
```

因此两个模型的输入、输出和 Demo 展示位置都不同。

## 2. 模型结构

推荐正式模型采用 `Risk-MLP 残差神经网络`：

```text
AIS风险特征
  -> 特征标准化
  -> MLP输入层
  -> Residual Block
  -> Residual Block
  -> Softmax风险等级输出
```

输出四类风险等级：

- 低风险
- 中风险
- 较高风险
- 高风险

## 3. 输入特征

风险模型使用的是风险相关特征，而不是船型分类序列：

- `behavior_score`：船舶行为异常分
- `encounter_score`：碰撞与会遇风险分
- `environment_score`：水域通航环境分
- `consequence_score`：船舶类型后果分
- `credibility_score`：AIS 数据可信度风险分
- `ahp_score`：AHP 综合风险分
- `avg_sog`：平均速度
- `point_count`：轨迹点数量
- `nearby_count`：近邻船舶数量
- `missing_static_flag`：静态船型信息是否缺失

## 5. 与船舶分类模型的区别

| 对比项 | 船舶分类深度学习模型 | 风险等级预测深度学习模型 |
|---|---|---|
| 目标 | 判断船舶类型 | 判断风险等级 |
| 输出 | 货船、油轮、渔船等 | 低/中/较高/高风险 |
| 输入 | AIS轨迹序列 | 风险特征和AHP分数 |
| 推荐结构 | 1D-CNN + BiLSTM + Attention | Risk-MLP 残差网络 |
| Demo位置 | 船舶画像、分类节点 | 风险评分、预警节点 |
| 作用 | 减少未知船舶 | 辅助风险预警 |

## 6. Demo 展示方式

点击船舶进入详情页后，系统显示：

- AHP规则风险分
- AHP风险等级
- 深度学习风险预测等级
- 深度学习风险置信度
- 融合风险等级

LangGraph 智能体流程也从四个节点扩展为五个节点：

```text
节点1 数据感知
节点2 船舶分类
节点3 AHP风险评分
节点4 深度学习风险预测
节点5 融合预警报告
```

## 7. 当前局限

当前风险模型使用 AHP 分数生成弱标签，因此它属于演示原型。后续如果要让模型更严谨，需要补充真实事故样本、专家标注风险样本，或者使用更长时间 AIS 历史数据构建正常/异常样本。
