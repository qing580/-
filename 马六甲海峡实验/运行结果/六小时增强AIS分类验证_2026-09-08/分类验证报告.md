# 六小时增强 AIS 数据分类验证报告

日期：2026-09-08。输入数据为 `原始数据/malacca_enhanced_ais_6h_2026-09-08_123520_473.csv`。本报告用于判断增强采集数据是否值得进入后续船舶分类实验，不作为论文最终准确率结果。

## 一、结论

本次 6 小时增强采集数据不是废数据。它同时包含动态轨迹消息和静态船舶消息，能够支撑一次货船/油轮二分类验证。

但是，当前结果只能说明“有弱提升迹象”，不能宣称船舶分类准确率已经显著提高。最佳 fallback 模型为逻辑回归，测试准确率 62.07%，测试宏平均 F1 为 0.5894；多数类基线测试准确率 55.17%，测试宏平均 F1 为 0.3556。测试集只有 29 艘船，结论仍不稳。

## 二、数据质量

原始 CSV 共 15460 行。按 MMSI 去空后得到 581 艘船。

按 AIS 船型码初步归类：

| 类别 | 船舶数 |
| --- | ---: |
| 未知 | 265 |
| 油轮 | 133 |
| 货船 | 114 |
| 拖带或港口服务 | 22 |
| 其他编码 | 18 |
| 客船 | 11 |
| 帆船或娱乐船 | 9 |
| 高速船 | 8 |
| 编码冲突 | 1 |

本次只选择货船和油轮，且要求最长连续轨迹分段不少于 10 个点、无同秒位置冲突。最终候选为 144 艘，其中油轮 79 艘、货船 65 艘。

## 三、实验设置

本次验证按船舶 MMSI 分组切分训练、验证和测试集，避免同一艘船同时出现在训练集和测试集。随机种子为 42。

当前运行环境没有 `scikit-learn`，因此 `classification_audit.py` 自动使用 numpy fallback 模型。本次模型包括多数类、最近质心、高斯朴素贝叶斯和逻辑回归。该 fallback 路径已写入脚本，保证不依赖临时安装包。

使用的轨迹特征包括：

| 特征 | 含义 |
| --- | --- |
| `speed_mean` | 最长连续分段平均航速 |
| `speed_sd` | 航速标准差 |
| `speed_median` | 航速中位数 |
| `speed_p90` | 航速 90 分位数 |
| `low_speed_fraction` | 低速点比例 |
| `speed_change_per_min` | 单位时间速度变化 |
| `turn_per_min` | 单位时间航向变化 |
| `path_m` | 最长连续分段估算航行距离 |

## 四、验证结果

| 模型 | 验证准确率 | 验证宏F1 | 测试准确率 | 测试宏F1 |
| --- | ---: | ---: | ---: | ---: |
| 多数类 | 55.17% | 0.3556 | 55.17% | 0.3556 |
| 最近质心 | 58.62% | 0.5857 | 51.72% | 0.5120 |
| 高斯朴素贝叶斯 | 58.62% | 0.5857 | 55.17% | 0.5496 |
| 逻辑回归 | 72.41% | 0.6947 | 62.07% | 0.5894 |

逻辑回归测试集混淆矩阵，类别顺序为货船、油轮：

| 真实类别 | 预测货船 | 预测油轮 |
| --- | ---: | ---: |
| 货船 | 5 | 8 |
| 油轮 | 3 | 13 |

从混淆矩阵看，模型更容易识别油轮，对货船召回较差。货船 13 艘测试样本中只识别出 5 艘，8 艘被预测为油轮。

## 五、能说明什么

1. 增强采集比旧采集更适合继续做分类实验，因为它保留了 `vessel_type`、船名、IMO、尺寸和 `raw_json`。
2. 货船/油轮二分类链路可以跑通，且按 MMSI 分组后没有训练测试泄漏。
3. 当前轨迹特征对油轮有一定识别信号，但对货船不稳定。
4. 相比多数类基线，逻辑回归在测试集上有小幅提升，但测试集太小，不能写成显著改进。

## 六、不能说明什么

1. 不能证明大模型或机器学习方法已经稳定提高船舶分类准确率。
2. 不能把 AIS 自报 `vessel_type` 当作完全真实标签。它是弱标签，仍需外部登记资料或人工核验。
3. 不能扩展为完整多类别分类结论。客船、高速船、拖带服务等类别样本太少。
4. 不能用本次 29 艘测试船反复调参后再宣称独立测试结果。

## 七、下一步

建议保留本次采集数据和验证输出，作为“增强采集可用性验证”。下一步不要急着堆模型，应先做两件事：

1. 外部核验一批货船/油轮标签，优先核验测试集和预测错误的船舶。
2. 增加独立日期或不同时段的新 6 小时采集，作为封存测试集，检验当前弱提升是否可复现。

如果外部核验后错误较多，说明主要问题是 AIS 弱标签不可靠；如果核验标签基本正确但新日期测试仍不上升，说明主要问题是短时轨迹特征对货船/油轮区分度不足，需要换特征、换区域或调整研究问题。
