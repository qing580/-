# 文献调研与技术路线确定

本文件夹用于保存马六甲海峡 AIS 船舶分类功能的文献调研、开源项目调研和技术路线说明。

## 文件说明

| 文件 | 内容 |
|---|---|
| `01_船舶分类论文调研记录_第一轮.md` | 记录已查到的 AIS 船舶分类、轨迹分类、半监督学习相关论文 |
| `02_GitHub开源项目调研记录.md` | 记录可参考的 GitHub 开源项目 |
| `03_船舶分类技术路线确定_建议版.md` | 给出本项目推荐采用的船舶分类技术路线 |

## 推荐阅读顺序

1. 先读论文调研，了解为什么当前“未知船”多；
2. 再读 GitHub 项目调研，了解别人怎么做；
3. 最后读技术路线建议，确定本项目后续怎么开发。
