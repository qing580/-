# 马六甲海峡船舶分类技术路线确定（建议版）

## 1. 当前问题判断

当前 Demo 中船舶分类结果里“未知”和“其他”偏多，主要原因有三个：

1. AIS 采集时间仍偏短，很多船只只收到动态位置报文，没有收到静态船型报文；
2. 当前分类主要依赖 `vessel_type` 船型码，缺少对轨迹行为的学习；
3. 货船、油轮等大型商船运动模式相似，如果没有船长、船宽、吃水、目的港等补充字段，单靠少量点容易混淆。

所以，问题不只是“分类种类太少”，也不只是“数据太少”，而是“静态字段缺失 + 规则法能力有限 + 轨迹特征没有充分利用”共同造成的。

## 2. 推荐最终技术路线

推荐采用：

```text
AIS 原始数据
  -> 数据清洗与轨迹分组
  -> 规则分类基线
  -> 轨迹统计特征提取
  -> Random Forest / LightGBM 机器学习分类
  -> CNN-BiLSTM 或 TCN 深度学习分类
  -> 规则、机器学习、深度学习结果融合
  -> 低置信度样本进入人工补全表
  -> Demo 右侧智能体报告展示分类依据
```

这条路线的优势是：既有文献依据，又能和当前项目逐步衔接，不会因为数据暂时不足而做出一个“训练不起来”的空模型。

## 3. 阶段设计

### 阶段一：规则基线

继续保留 AIS `vessel_type` 映射：

- 70-79：货船；
- 80-89：油轮；
- 30：渔船；
- 60-69：客船；
- 31/32/52/53：拖轮或港口服务船；
- 其他编码：其他或未知。

作用：保证分类结果可解释，并为模型训练提供弱标签。

### 阶段二：轨迹特征机器学习

按 MMSI 汇总轨迹，提取：

- 平均速度、最大速度、速度标准差；
- 平均航向变化、最大航向变化；
- 转向率统计；
- 轨迹点数量；
- 经纬度跨度；
- 停留比例；
- 是否在港口附近低速停留；
- 是否长期沿主航道直线航行。

模型建议：

- 首选 Random Forest：好解释，适合答辩；
- 备选 LightGBM / XGBoost：效果通常更强，但解释成本略高。

输出：

- 预测船型；
- 分类概率；
- 特征重要性；
- 是否建议人工复核。

### 阶段三：轨迹序列深度学习

将每艘船按时间排序，构造序列：

```text
[lat, lon, sog, cog, heading, rate_of_turn, time_delta]
```

模型建议：

- 小数据阶段：1D-CNN + BiLSTM + Attention；
- 数据更多后：TCN 或 Transformer；
- 如果轨迹图像也加入：轨迹图像 CNN + AIS 序列 TCN 双分支融合。

输出：

- 深度学习预测船型；
- 置信度；
- 与规则分类是否一致；
- 与机器学习分类是否一致。

### 阶段四：半监督与人工补全闭环

把船舶分为三类：

1. 规则和模型一致，且置信度高：自动采用；
2. 规则缺失但模型置信度高：作为伪标签候选；
3. 规则和模型冲突，或模型置信度低：进入人工补全表。

人工补全表字段建议：

| 字段 | 含义 |
|---|---|
| mmsi | 船舶唯一识别码 |
| vessel_name | 船名 |
| rule_category | 规则分类 |
| ml_category | 机器学习分类 |
| dl_category | 深度学习分类 |
| confidence | 综合置信度 |
| suggested_category | 系统建议类别 |
| manual_category | 人工确认类别 |
| review_reason | 需要复核的原因 |

## 4. 创新点表述

本项目可将创新点表述为：

> 针对短时 AIS 采集中静态船型字段缺失导致船舶类别识别困难的问题，构建规则基线、轨迹统计机器学习、轨迹序列深度学习和人工补全反馈相结合的多阶段船舶分类方法。该方法不仅利用 AIS 上报船型码，还从船舶运动行为中学习类别特征，并通过低置信度样本复核机制逐步提升模型可靠性。

## 5. Demo 中如何体现

Demo 不建议只在地图上显示颜色或图标，而应体现“智能分析过程”：

1. 地图首页只显示船舶位置、船型图标、风险视觉提示；
2. 点击船舶后进入详情页；
3. 详情页显示：
   - 规则分类；
   - 机器学习分类；
   - 深度学习分类；
   - 综合分类；
   - 风险等级；
   - 模型置信度；
   - 为什么这样判断；
   - 是否建议人工复核。

## 6. 下一步建议

建议下一步先做“机器学习特征分类基线”，因为它最适合当前数据量，也最容易形成可解释结果。等 AIS 数据积累到 6 小时、12 小时或多天后，再训练更正式的 CNN-BiLSTM/TCN 深度学习模型。

这样项目路线会更稳：

```text
规则法可解释
机器学习有效果
深度学习有技术高度
人工补全有闭环
Demo 展示有智能体分析感
```
