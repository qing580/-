# 正常状态转换与异常运动：相关论文清单

检索日期：2026-09-05。状态：针对性初查，不是系统综述；未下载全文 PDF，未确立创新优先权。

## 判断

存在直接及相邻研究。状态识别、状态转换、变化点检测、异常判别不能混同；隐状态也不自动具有真实作业含义。尚未核实有论文同时完整覆盖多船型、真实作业转换、自然环境及独立标注的正常/异常转换评估，不据此宣称空白。

## 核心条目

1. Identifying fishing trip behaviour and estimating fishing effort from VMS data using Bayesian Hidden Markov Models (2010). Ecological Modelling 221(15), 1757–1769. https://doi.org/10.1016/j.ecolmodel.2010.04.005
   - 出版社摘要已核对：以贝叶斯 HMM 建模捕鱼、航行、停留及其转换，运动参数依状态变化。
   - 相关性：正常状态转换建模基础；使用 VMS，不是直接的多船型 AIS 异常识别方法。不能将 HMM 的应用本身称为创新。

2. Unsupervised Behavior Change Detection in Multidimensional Data Streams for Maritime Traffic Monitoring (2019). Lucas May Petry, Amilcar Soares, Vania Bogorny, Stan Matwin. https://arxiv.org/abs/1908.05103
   - 作者页面明确为提交 MAIS 2019 的 extended abstract；探讨无监督/半监督行为变化检测。
   - 相关性：从数据流定位行为变化；不作为已充分验证的综合算法成果。变化不必然是异常。

3. Context-Aware Autoencoders for Anomaly Detection in Maritime Surveillance (2026). https://arxiv.org/html/2602.00124v1
   - 上一轮已读取方法与评估：船型和航行状态构成上下文，比较条件阈值及条件解码器。
   - 相关性：状态条件下的异常判别，与用户问题高度接近；并不因此证明其专门评估连续转换过程。作者版缺少标注真值，不能由告警更多推断精度更高。

4. A framework for ship abnormal behaviour detection and classification using AIS data (2024). Reliability Engineering & System Safety. https://doi.org/10.1016/j.ress.2024.110105
   - 出版社方法片段：滑动窗口分析速度、航向与横向偏离，定位并聚合异常时段，再进行异常行为分类。
   - 相关性：从异常点扩展为有起止时间的事件；文中讨论补充船型和海气信息的价值，不能把讨论方向误报为已实现输入。

5. PhyEnv-GAN: Incorporating vessel kinematics and sea-state condition for anomaly detection of shipping behavior (2026). Ocean Engineering, 127250. https://doi.org/10.1016/j.oceaneng.2026.127250
   - 本轮获取更完整出版社摘要：海况条件生成、TCN 判别及运动学约束，用于正常轨迹建模和异常识别。
   - 相关性：环境导致的轨迹变化；未确认显式作业状态转换建模。摘要的重构误差改善不能换写成异常准确度提高。
   - 摘要提供代码线索 https://github.com/LiangZhao13/PhyEnv-GAN ，本轮未打开核验许可证、完整性或运行情况。

6. A Hybrid Statistical and Neural Network Method for Detecting Abnormal Ship Behavior Using Leisure Boat Sea Trial Data in a Marina Port (2025). JMSE 13(12), 2391. https://doi.org/10.3390/jmse13122391
   - 出版社公开内容：统计准则结合 LSTM，基于休闲船试验识别运动偏离。
   - 明确局限：未进一步区分真实异常与传感器噪声、环境扰动、操作差异导致的误报。该局限只属于该工作，不代表全领域未解决。

7. Evaluating models for classifying movement of whale-watching vessels (2023). Ecological Informatics 73, 101903. https://doi.org/10.1016/j.ecoinf.2022.101903
   - 使用 AIS 比较 HMM、DBSCAN 和逻辑回归，以实际观测验证行为识别。
   - 相关性：独立行为验证的设计参考，非异常转换检测；不扩展其结论到货船或油轮。

## 补充待核实

EASY: Exponential Attention with State-Space-Based Yearning Network for Ship AIS Abnomal Detection (2025), https://www.preprints.org/manuscript/202505.1417 。标题按页面原样保留；页面为未同行评审预印本，提出状态空间与指数注意力。数学状态空间不等于航行/作业阶段，精读前不作直接转换检测证据。

## 研究边界与下一步

不能声称首次研究船舶状态转换、首次 HMM 检测船舶行为或首次环境条件异常检测。候选问题应明确到某类转换（例如正常等泊减速与异常减速）及其可核验标签，比较状态条件模型、转换模型、环境拼接与拟议联合机制。

优先精读第1、3、4、5篇；第6篇用于厘清误报与验证边界。建立对照矩阵：显式船型、状态来源、转换概率/持续时间、环境类型、是否异常判别、独立标签、训练测试划分及公开代码。没有确认的数据和发表信息保留待核验，不补编。
