# 船舶分类论文调研记录（第一轮）

## 1. 调研目的

本轮调研围绕“如何提升 AIS 船舶分类准确率，尤其是解决 vessel_type 缺失导致大量船舶被分为未知”的问题展开。调研重点不是继续扩大规则表，而是寻找有论文依据、能体现技术含量的机器学习与深度学习方法。

当前项目的核心困难是：AIS 动态报文中常有 `lat、lon、sog、cog、heading、rate_of_turn` 等运动字段，但 `vessel_type、vessel_name、imo、call_sign` 等静态字段并不一定及时出现。因此，仅靠船型码映射会产生大量“未知”结果。

## 3. 关键结论

### 3.1 只靠 AIS 船型码不够

AIS 的 `vessel_type` 属于静态信息，不一定在短时间采集中出现。如果只根据这个字段做分类，未知船比例高是正常现象。文献中也明确关注了“limited ship information”“unlabeled trajectory data”等问题。

### 3.2 轨迹行为可以用于船型分类

船舶类型会影响运动模式。货船、油轮、客船、渔船在速度分布、航向变化、停留行为、转向频率、航道使用习惯上有差异。因此可以从 AIS 动态轨迹提取特征，再用机器学习或深度学习分类。

### 3.3 小数据阶段不建议直接只上复杂深度学习

本项目目前马六甲 AIS 数据量还不大，直接训练大模型容易过拟合。更稳妥的路线是：

1. 规则法作为基础标签；
2. Random Forest / LightGBM 作为可解释机器学习基线；
3. CNN-BiLSTM/TCN 作为轨迹序列深度学习模型；
4. 低置信度样本进入人工补全表；
5. 数据积累后再做轨迹图像 + AIS 序列融合模型。

## 4. 推荐引用方式

答辩时可以这样解释：

> 本项目最初采用 AIS 船型码映射，但短时间 AIS 采集中静态船型字段缺失严重，因此未知船比例较高。相关研究表明，可以从 AIS 轨迹中提取速度、航向、转向率、空间跨度、停留比例等特征，使用 Random Forest、LightGBM、CNN、LSTM、TCN 等模型进行船型识别。进一步的研究还采用半监督学习和多模态融合方法，利用少量有标签数据和大量无标签轨迹提升分类效果。因此本项目拟采用“规则基线 + 轨迹特征机器学习 + 半监督深度学习 + 人工补全闭环”的技术路线。
