# 海上异常检测智能体：研究方向与多源数据讨论

日期：2026-09-05。项目名称：基于大模型海上异常检测智能体的构建。
状态：方向讨论，用户尚未选择主线；未改 Demo，未开展训练。本记录不构成创新查新结论或论文发表保证。

## 一、重新界定研究中心

船舶分类作为船型背景与条件变量，服务于异常检测。优先面向监测人员的告警复核需求：发现可疑行为，补充环境和地理证据，给出可追溯的结论与不确定性。

必须区分：统计异常（偏离常见行为）、危险程度（可能后果与暴露）、违规判断（适用规则和事实证据）。三者不等价。AIS 中断不能直接等同故意关闭设备；气象相关性不能直接证明异常的原因。

当前截图所示采集框为北纬 1.0–3.5、东经 103.0–104.5，主要研究区域应明确为马六甲东南部及新加坡海峡附近，不能称覆盖整个马六甲海峡。正式边界需核对原始采集配置。

## 二、候选研究路线

### A. 多源情境约束的异常告警复核智能体（推荐优先论证）

研究问题：在减少误报的同时，保留对真正值得复核事件的检出能力；在证据缺失、冲突或分辨率不足时表达不确定性。

首期行为范围：异常减速或长时间低速停留；航线偏离或异常转向。周边会遇关系作为解释和风险证据，暂不扩展为全面自主避碰。

候选流程：轨迹窗口与质量检查 → 规则/机器学习提出候选事件 → 按时空查询航道、锚地、气象、邻船 → 数值工具计算 → 检索适用通告与案例 → 结构化证据核对 → 保留告警、降低告警优先级或待人工确认。

候选贡献一：考虑数据缺失、时效与尺度的情境条件异常评分。与普通特征拼接、上下文自编码器逐项比较；尚不能声称新颖。

候选贡献二：依据事件类型和证据缺口选择下一项查询，设置调用预算与停止条件。比较固定查询和自适应查询的事件效果、成本及延迟。主动查证与工具调用本身不是首次提出。

候选贡献三：对每条解释绑定证据来源、观测/有效时间、查询时间、工具输出与适用范围，核对冲突并允许弃答。需要证明这种领域约束优于普通 RAG 或固定报告，而不只是展示引用。

### B. AIS 缺失与异常中断的可靠性诊断

研究数据中断是接收覆盖不足、通信问题还是需要关注的异常。需接收站/覆盖证据、邻船同期接收情况，或独立遥感观测。未取得独立证据前只输出可疑中断，不判断恶意关闭。独立证据获取是主要障碍。

### C. 风浪环境下的航行风险预警

AIS 与风浪流、船型及地理环境融合，研究短期风险变化。需要足够多环境条件和可靠事件标签；单次六小时采集不支持极端天气结论。适合有历史事件和更长时间数据后扩展。

## 三、数据优先级与来源

| 数据 | 作用 | 候选官方来源与获取方式 | 约束 |
| --- | --- | --- | --- |
| AIS 动态与静态消息 | 行为、邻船与船舶背景 | 现有 AISStream 订阅；保存原始消息、接收时间、类型 | 覆盖非完整；先审计静态关联；原始点数不是独立船数 |
| 风速风向等 | 情境条件 | ERA5：CDS 下载或 API | 全球再分析，具有发布延迟；用于回顾研究，不伪装当时可用预报 |
| 海浪、海流 | 相对风浪流与航行环境 | Copernicus Marine 全球波浪/物理产品，Toolbox 子集下载 | 模型/融合产品非逐船实测；核对产品网格、时间覆盖和沿岸有效值 |
| 航道、锚地、岸线 | 区分等泊、航道通航与偏离 | MPA 官方通告/港口资料；可许可公开地理数据 | 官方通告公开不等于所有电子海图免费；确认版本、版权和空间精度 |
| 水深与海底地形 | 地理背景、粗尺度浅水接近线索 | GEBCO 全球格网 | 15 角秒，不能作精细海图；欠缺潮位、吃水和误差时不能精确预测搁浅 |
| 通航通告与事故调查 | 大模型检索和人工标注参考 | 官方 MPA 通告及相关事故调查机构公开报告 | 核对地域、事件时段和有效版本；历史事故往往无法与现有 AIS 精确匹配 |
| 热带气旋路径（扩展） | 历史极端天气专题 | NOAA IBTrACS | 最佳路径属回顾资料；近赤道当前区域直接气旋样本稀少，不宜首期主线 |
| 叶绿素/赤潮信息（暂缓） | 生态专题 | 海色产品和当地权威监测公告，具体区域产品待核对 | 高叶绿素不等于有害赤潮；NOAA 美国监测不是马六甲现场真值 |
| SAR/光学影像（后续） | 独立观测核验 | 候选 Sentinel 数据，后续验证可用场景 | 过境时刻、分辨率、云层或配准、标注限制；本轮未核验具体影像 |

首期建议 AIS + 航道/锚地地理信息 + 风浪流 + 权威文本证据。水深作为辅助。每个来源必须对应一个能够改变判断的问题，不能只堆地图图层。

## 四、方法与智能体职责

- 轨迹预处理：质量过滤、分段、时间对齐和空间连接；时间间隔、数据缺失和插值标记要保留。
- 规则、邻域距离与 DCPA/TCPA：作为可解释工具，明确匀速直线等假设，不交给语言模型口算。
- 机器学习基线：Isolation Forest 等用于候选异常，随机森林或梯度提升用于有可靠标签的分类。无监督异常分数不自动代表危险。
- 时序模型：数据充足后比较 GRU、TCN 或自编码器，先选一种适配模型而非堆叠。上下文模型需与无上下文基线对照。
- 大模型：围绕事件选择查询、检索通告、综合结构化证据并生成可追溯解释；不能凭文字猜测数值或把没有证据的推断写成事实。
- 编排：候选 LangGraph，适合状态保存、条件分支、工具和人工复核。框架是工程基础，不是论文创新。
- 框架中的节点是执行步骤，并不意味着每个节点都是独立智能体。首期一个编排智能体加专业工具即可。
- 船型未知时保留未知及置信信息，避免错误船型继续污染风险判断。
- 既有 AHP 分数只能按实际依据作为专家/规则基线。若用 AHP 生成风险标签再训练模型，只能证明拟合该评分规则，不能据此证明真实风险识别准确。

## 五、论文验证计划

基线：AIS-only 检测；固定多源融合；固定多源融合加普通 LLM/RAG；候选证据约束/主动查证方法。保持输入机会与计算预算可比，分别做质量约束、证据选择和冲突处理消融。

检测层：事件级 precision、recall、F1、误报次数/船小时、告警延迟。降低误报需同时报告漏报，不能以全部不报警取得好指标。

解释层：由可核对证据和人工审阅评估事实正确率、引用支撑率、遗漏与无依据断言；仅有 LLM 自评分不够。

决策层：正确复核比例、待确认比例、错误高置信结论比例；主动查询另报告调用次数、token 和延迟。

数据划分：按船舶及日期阻断泄漏，禁止重叠窗口跨集合；历史回放中的在线实验只允许使用当时已可获取的信息。回顾性再分析实验与在线实验分开报告。

标注：制定正常/可疑事件定义，优先两名标注者独立判断并处理分歧，记录一致性。仅有行为异常标签不能宣称事故风险真值。人工合成事件单独报告，不替代真实场景检验。

采集规模：六小时用于链路验证与案例探索。按独立船数、船小时、事件数、天气与交通状态覆盖决定后续采集量，不能预先保证某个小时数足够发表。连续多日/不同条件采集的建议须经数据可用性审计。

3. AIS-LLM: A Unified Framework for Maritime Trajectory Prediction, Anomaly Detection, and Collision Risk Assessment with Explainable Forecasting。预印本：https://arxiv.org/abs/2508.07668 。已存在大模型与 AIS 多任务结合，排除“大模型接 AIS 就是创新”的表述。
4. Context-Aware Autoencoders for Anomaly Detection in Maritime Surveillance。预印本：https://arxiv.org/abs/2602.00124 。上下文异常检测已有研究，需全文核对上下文类型与本项目差异。
5. VLMAR: Maritime scene anomaly detection via retrieval-augmented vision-language models。出版社摘要入口：https://www.sciencedirect.com/science/article/pii/S1047320325002834 ，DOI：https://doi.org/10.1016/j.jvcir.2025.104669 。检索摘要显示 AIS/SAR 和检索增强结合；本轮直接打开失败，数据集和代码开放性未核实。
6. Multi-Field Hybrid Retrieval-Augmented Generation for Maritime Accident Root Cause Analysis。预印本：https://arxiv.org/abs/2606.13249 。事故根因分析与实时告警任务不同，仅为相邻研究入口。

8. ERA5 官方：https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=documentation ，DOI：https://doi.org/10.24381/cds.adbb2d47 。全球小时再分析；核对访问时实际时间范围。
